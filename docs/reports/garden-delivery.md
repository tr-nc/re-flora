# 花园、喷水性能、声音与湿草：本轮交付报告

2026-10-21。四项功能和验收中发现的生命周期问题已合入本地 `main`。
实现与验收记录截至 `6e367fc9`；主工作树已重新构建默认验证层 Release，并完成独立隐藏静音复验。
**本轮实现完成，但重喷头场景的掉帧尚未彻底消除；美术和听感仍待玩家批准。**

没有推送、正式打包、启动可见游戏或播放声音。现有设置和用户世界没有被替换。

## 1. 已交付的四项行为

### 喷水性能

先测量 0/1/4/8/16 个喷头，再保留两项精确优化：

- 喷流准备从 64 扩展到 256 lanes，让同一实例的独立样本并行处理；CPU 按逻辑工作组提交，
  不会因 local-size 改变漏算实例。
- 浇水时复用稳定的有效 contact 索引列表，不再让每个 receiver 重复扫描全部无效槽。

没有减少 256 个共享喷流/接触样本、128 个光学水滴、水量、占空比、画质或硬件姿态。
单物理喷口、近远覆盖、首次接触、墙体/台阶、光学独立开关、四种造型和 16 个完整装配姿态保留。

### 空间喷水声

普通游戏中成功放置喷头后自动发声，复用已有 **Audio → Terrain** 分类和主混音：

- 100% 占空比为持续水声；中间值按同一阀门相位间歇发声；0% 静音。
- 读取 **实际上传给 GPU 的同一份 `SprayClock` 快照**，没有第二个喷水时钟。
- 采样域包络支持 20 Hz 与低渲染更新率，带短边缘平滑和 200 ms 陈旧控制静音。
- 最多 16 个总声音槽（包括准备、播放和退役），稳定 ID、距离选择与迟滞；更多喷头仍全部灌溉。
- 放置/删除、暂停、混音禁用、成功/失败读档及关闭均经过真实生命周期验证。

采用原创程序合成的共享 4 秒 mono 水噪声，约 0.733 MiB；不需要模型、联网推理或第三方音效样本。
这是候选水声，不模拟真实管路压力、每个落点或机械撞击臂。当前输出块/预缓冲/设备仍有延迟，
不宣称逐采样声画同步。200 ms 不包含已经进入设备缓冲的音频。

### 新花园开局

普通新开局现在是可编辑的花园：偏心入口空地、连接第二片空地的通道、宽缓且不对称的起伏、
四棵成组树、三种颜色的花带及少量离群个体、矮草与局部高草。

- 默认种子 `20260519`；`--garden-seed <u32>` 在固定构图中改变个体分布。
- 默认实现场景包含 **130,010 株普通草 + 180 株已建立的花、4 棵树**；不是仅有 180 个植被实例。
- 通过普通 terrain/Grow/plant/Trim/Mow 路径建立，之后可挖、种、割，不会逐帧重新填满玩家改动。
- 真实角色胶囊走完通道；实际挖土、种植、割除及保存/恢复通过。
- **加载存档优先，即使是完全空白存档**；不会在加载后重新生成花园。
- `--legacy-terrain` 保留旧程序地形；`--flat-terrain`、特殊场景与诊断场景保持各自所有权。
- 没有为截图修改保存的光照、画质或相机库。

这些是空间生态研究启发的美术初始条件，不是完整生态模拟，也不宣称不同物种普遍互相吸引或排斥。
新场景本身比旧默认内容更重：世界切片测量额外 GPU 成本约 2.1–2.8 ms；那是不同初始内容的比较，
不是隔离某个材质开关的成本。不能用喷水优化收益掩盖新增植被的成本。

### 草的湿度外观

高草和矮草复用现有支撑土壤 atlas 的四档湿度，在 stress tint 后、照明前对线性底色作温和暗化，
最大 25%。花、树和果实不应用该材质变化。

- 默认开启，保存的对照开关：**Debug → Moisture Appearance → Grass soil-moisture darkening**。
  取消勾选恢复原材质，不改变生长或水分。
- cached/native 路径共享函数；复用原有支撑采样，不添加反射 pass、纹理、CPU 逐草查询或独立湿区。
- 手动浇水、喷头、土壤转移、干燥、湿土重种和存档恢复使用同一真实水分来源。
- **这是根部/土壤湿度的外观代理，不是叶面储水模拟。** 停水后土仍湿，草仍暗；最终画面变化受
  光照、曝光和喷雾遮挡影响，也可能显示四档变化。

30,542 株草的三轮开关对照中，GPU preparation/draw 的差值处于运行噪声内；不能因此宣称严格零成本。

## 2. 完整花园的性能结果

同一实现后的花园存档、相机、质量、声音及真实水动态，RTX 3060 Ti / i5-12600KF，
原生窗口 **4096×2560**、保存的 stride=5 对应 **820×512 内部分辨率**，自动 FIFO。
每个喷头独立按实际地形接地，人口递增使用固定位置前缀。

对照是在**当前全部功能不变**的构建中，仅恢复两份优化前喷水 shader；不是把旧空场景与新花园比较，
也不是把这个重建对照冒称历史原始二进制。两侧 dispatch、反射 ABI、所有实例的 GPU 活跃源和声音
均已检查。主矩阵及连续/重叠压力共 **66 次**交错 Release 运行，每 case/版本三轮，充分预热后每轮
193–526 个 GPU 样本。性能运行无验证层，正确性运行有验证层。

当前保存的 30° / 5 RPM / 5 Hz / 30% duty / mist intensity=6，水滴开启。以下 GPU 数值是三轮
各自 p50/p90 的算术均值（ms），FPS 是实际帧日志节奏，不是由 GPU 时间取倒数：

| 喷头数 | 优化前 GPU p50 / p90 | 优化后 GPU p50 / p90 | 实际平均 FPS 前 → 后 |
| ---: | ---: | ---: | ---: |
| 0 | 8.702 / 8.930 | 8.301 / 8.529 | 58.42 → 58.42 |
| 1 | 10.014 / 10.645 | 9.269 / 9.669 | 58.41 → 58.50 |
| 4 | 13.939 / 15.833 | 12.440 / 14.281 | 58.42 → 58.45 |
| 8 | 19.158 / 22.182 | 16.606 / 20.041 | 49.58 → 53.87 |
| 16 | 26.642 / 30.008 | 22.734 / 26.421 | 35.76 → 41.74 |

**0 个喷头的差异是非喷头运行波动，不能归功于喷水优化。** 未改的草 raster 出现两档成本，原因尚未
用硬件计数器定位。扣除各自 0 人口 frame p50 后，1/4/8/16 个的边际成本减少约
0.344 / 1.098 / 2.152 / 3.508 ms。分阶段的百分位不能相加冒充整帧百分位。

16 个喷头的关键 GPU 阶段 p50：

| 阶段 | 前 → 后（ms） |
| --- | ---: |
| 准备 | 0.710 → 0.231 |
| 浇水 | 4.006 → 0.670 |
| 水雾/光学水滴 | 12.783 → 12.430 |
| 硬件绘制 | 0.677 → 0.677 |
| 同帧喷头 scope 和的 p50 | 18.286 → 14.027 |

16 个连续喷水：GPU frame 31.933 → 25.763 ms，实际约 29.98 → 37.10 FPS。
**重场景仍未达到 60 FPS；当前首要热点是水雾光学，不再是准备或浇水。** 下一步应测精确的活跃/有限
支持候选压缩，而不是减水、减粒子、降低保存画质或继续猜已经很小的准备阶段。
完整 CPU/GPU、p90、重复与压力矩阵见 [最终验收报告](garden-final-acceptance.md)。

## 4. 研究及许可选择

- [音效工具与许可](../research/sprinkler-audio-tools.md)：AudioGen 的 MIT 代码不等于其 CC BY-NC
  权重可用于本次商业游戏素材；TangoFlux 有研究/非商业限制；Stable Audio Open 1.0 的精确模型
  条款因访问限制未完整核验。未注册、接受 gated 条款、下载权重或交付这些模型的输出。
  选择原创 DSP，避免新增模型/样本许可依赖；项目与现有依赖的许可仍适用，未擅自标记 CC0。
- [花园空间生态](../research/garden-spatial-ecology.md)：同种聚集、种间关系、尺度与环境过滤的
  一手研究；实现采用花带、离群个体、软空间偏好与玩法留白，不夸大为生态规律仿真。
- [低成本湿材质](../research/vegetation-wet-materials.md)：支持温和材质响应的来源、土壤湿度
  与叶面湿润的区别，以及没有新增反射路径的实现取舍。

## 5. 验收中实际修复的问题

1. **全空世界读档等待水发布**：初始化错误要求存在非空 collider。现在完整域已观察且依赖全部完成
   即可 Ready；未观察和 pending 不得冒充空域。旧保留基线也能复现，准确引入提交未知。
   空/非空往返、最后实体移除、stale worker、实际两次读档均通过。[根因记录](empty-world-reload.md)
2. **读档开始后旧声音未退休**：世界依赖推进许可不等于声音准入许可。接受 Load 时立即退休声音，
   用独立音频 readiness 等待依赖完成；可恢复失败可再次准入，致命失败仍静音。实际红/绿验证覆盖
   活跃 16 声音、花园/空世界、失败重试及 session 喷头 ID/位置/phase 精确保留。
3. **暂停后湿土仍变化**：soil spread/dry 和喷头 dose 的提交未跟随世界 running 事实。现在共用该事实，
   暂停时将 staged dose 归零。没有新湿度时钟或独立材质时间。

后两项详见 [最终验收第 1 节](garden-final-acceptance.md#1-具体审查发现与红绿修复)。
