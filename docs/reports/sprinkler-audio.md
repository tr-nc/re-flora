## 历史实现及验证（scope v3，以下程序 DSP 描述已被上文替代）

## 交付行为与所有权

采用[工具及许可研究](../research/sprinkler-audio-tools.md)选定的**原创程序 DSP**，没有下载模型、使用 AI 输出、注册服务或引入第三方采样许可。四种喷头外观使用相同声音：安静的滤波水噪声与阀门开启时的短促水流纹理。不是机械撞击模拟；现有静态撞击臂没有同步动画。

普通花园中成功放置喷淋器后，提交的稳定 ID、基座位置与 `animation_phase` 才会进入空间音频。预览、未提交事务及失败放置不建立声音。复用原有 Terrain 分类、主音量、距离衰减、空间化与遮挡；可在现有 Audio 分组调整/禁用 Terrain 分类。没有新设置、迁移或默认值改写。

单个共享 4 秒、48 kHz、mono f32 纹理约 0.733 MiB，在初始化时生成，不在实时线程合成或分配。噪声的循环接缝有 10 ms 平滑窗口。每源一条声音，水声与脉冲共享同一 PCM 和包络；没有每水滴声源、GPU 碰撞回读或脉冲播放队列。

## 精确时钟和延迟契约

`Tracer` 仍独占原有 `SprayClock`，每次 render-input 更新只采样一次。新增 `SpraySnapshot` 保留**实际上传**的 `[f32;4]`、统一归一化的频率与占空比。数组 `[1]` 是周期内秒数，不是归一化相位；声音以 `frac(pulseSeconds * Hz + frac(animation_phase)) < duty` 表示源年龄为零的阀门。

在该更新之后，应用的原有 `SpatialFrame::advance` 接收快照及已提交来源，执行 prepare → 同一次完整空间发布 → play。没有第二时钟、第二发布器或额外遥测 drain。水雾密度、粒子、浇灌倍率与转速不是声音开关；0 RPM 仍可喷水。

PetalSonic 新增可附着在 resident clip 上的小型 `SampleEnvelopeControl`。单写者使用固定原子字段和序列号发布最新相位，实时端每块最多一次无锁读取，不重试等待、不分配，之后逐采样外推。每次更新重新锚定，不积压历史脉冲。频率修改保留原有时钟相位。当前世界时钟的正常速率为实时 1x；暂停/世界替换不允许更新时清空声音，恢复以新快照重建，不追赶过去的水声。

- 100%：连续水噪声，**没有周期性开启纹理**；0%：退役全部喷淋声音。
- 中间占空比：0.25–20 Hz 采样域阀门，低渲染帧率不会把 20 Hz 简化成帧级开关。
- 阀门边缘约 1 ms 平滑，窄脉冲的内部边缘缩短为开启窗的 1/4；全局斜率限制有至多约 1 ms 的尾部，并非数学意义上的硬方波，不能把短脉冲延长成连续喷射。
- 控制未刷新最多 200 ms 后进入静音，再加约 1 ms 释放。控制读取竞争时本块保留旧状态，但旧状态仍会到期。
- 相位在消费新控制块时重新锚定，不把排队延迟当作新的世界推进。音频块、引擎预缓冲、设备/系统输出仍有实际延迟；不声称声画逐采样同时到达。200 ms 是控制渲染上界，**不是**包含设备缓冲在内的端到端静音上界。

## 生命周期及资源上界

最多 **16 个总槽位**，包括已准备、播放中与退役中的声音。按可听范围 32 世界单位内的距离选择，已有成员有 20% 距离迟滞，稳定 ID 解同距；超过 16 个喷头仍全部正常浇水。实际听感距离仍受原有衰减控制。

失败发布会静音并取消准备/已有声音；创建或播放失败只影响声音，不回滚灌溉。销毁失败保留声源句柄、槽位和静音控制，在后续帧重试。销毁成功后，仍需等包络共享引用证明排队/渲染/退役端已释放所有权，才归还槽位；无设备/渲染停顿时宁可延迟新声音，不突破上界。删除、暂停、主/分类禁用、世界更新静止及关闭都使用同一退役路径；CLI `--mute` 保留处理、使用原有主混音静音。

## 保真度边界与待验收

这是一版可用候选水声，不是录制或经过玩家听审的真实喷头音效。不模拟落点声场、每个喷孔方向性、硬件机械碰撞或真实管道压力。所有喷头共用同一纹理，密集同相源可能相关；固定源增益提供默认前级余量，但用户把已有混音增益放大到极端值仍可能触发现有总线限幅。新增功能不承诺任意用户增益下绝不限幅。人工试听与声音美术审批仍待玩家决定。

### 最终验证、调度和剩余验收

扩展原生 fixture 的 0 RPM / mist=0 / particles=false、20 Hz、0%/100%、暂停恢复及删除断言，在 0/1/4/8/16/20 的无验证层性能轮次全部通过；随后恢复默认验证层，在 `native-final-20.log` 再次通过 20 来源完整序列、正常关闭、无验证错误。普通无 fixture 花园的 `cargo run --release -- --hidden --mute --auto-exit 0.5` 也通过（`final-smoke.log`，使用 `--latest-log` 确认了同一 worktree 的原生日志）。
