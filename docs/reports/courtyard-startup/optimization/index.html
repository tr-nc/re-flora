最大的三处浪费，分别消掉

01 / 空间索引

不再逐点遍历全部枝干

使用既有圆锥空间索引裁剪查询，保留精确 signed_distance <= 0 判定。空材质、可复用木材、根部土壤和世界边界规则未放宽。

02 / 原子事务

五棵树，一次森林发布

初始树木先准备，再通过原有事务所有者提交。整片树表面从五次准备变成一次，保留单树 ID、生长时钟、树叶、果实、音频和失败回滚。

03 / 稀疏遍历

空的树结构，不逐体素追踪

碰撞体导出沿实际存在的 Contree 节点裁切目标块，跳过空子树。初始导入约 3.6–3.8 s → 0.79 s；材质掩码、依赖版本与就绪策略不变。

另外，树表面片段改为按已有的保守“枝干 + 半径二采样支撑域”判断材质变化；准入和编译共享同一份不可变树几何，不再重复生成相同骨架。没有引入全局树缓存，也没有调低导入预算或视觉质量。
