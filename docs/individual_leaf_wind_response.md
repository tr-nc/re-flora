# 逐叶风响应

2026-09-06。用户指出球形叶簇一起摆动不自然，要求树叶单独计算。本轮不改树形、草/花响应、果实碰撞或已保存的 GUI 参数；视觉效果仍需用户试用确认。

## 原因与状态归属

旧 C 虽在叶片实际 XZ 位置采样共享叶片 map，但同一叶簇共用姿态桶，且最终位移乘以离叶簇中心的径向权重平方，因此运动仍有整球呼吸感。

现在每个**可见叶体素**拥有自己的连续位移/速度和四份离散已发布姿态。它不是每个网格顶点一份状态，也不是另起一份物理求解器：仍使用 `vegetation_response_solver.slang` 的解析阻尼振子。叶片在自身位置读现有风场，按固定世界位置种子产生小幅机械差异：频率 ×0.75–1.25、阻尼 ×0.8–1.2、响应增益 ×0.85–1.15。没有额外时变随机力，整体风向保持一致。

移除叶片相对叶簇中心的径向风权重，姿态桶改用各叶的世界位置种子。近景、远景和照明缓存共用同一准备函数及树内实例索引；原有叶色种子不变。现有风场仍只使用 XZ，不声称已加入高度风、树冠遮挡、叶片碰撞或枝条骨骼。

`vegetation_response/leaves.rs` 封装状态归属：树 ID、世界体素位置和附着点局部坐标共同识别叶片。渲染顺序、树数据重打包不会改变同一叶片身份；新增、移位或重种的叶片从零状态开始，消失的身份在下一帧移除。树龄改变导致几何位置改变时，不把不同组织的速度硬接过去。显隐和新旧视觉切换仍后台推进。

阴影仍用原有 2/4-voxel 聚合代理，保持光学面积、数量和历史策略。重建时记录代理的实际成员索引和各自姿态种子，绘制时平均这些成员的已发布位移；不再独立采样叶簇运动。可见实例仍为 8 字节，阴影实例从 16 变成 24 字节，另有每叶 8 字节成员引用。资源沿现有在途帧退休机制回收。

共享场从草/叶/苹果三张改为草/苹果两张；苹果事件读回同步移到第二张场，不改变挂果角摆或落果速度转换。

## 验证

- 先增加生产 GPU 回归：同位置、同风力、不同叶种子。旧实现差异为 0，按预期失败；逐叶实现最大差异 0.347367，超过 0.02 断言。
- 6 项响应单测、6 项阴影代理单测通过。新增覆盖逐叶重排/重打包/删除/新树身份、可见/阴影 ABI、每片叶恰好属于一个阴影代理。
- 主 Rust 套件 880 passed、1 ignored、1 filtered；仅过滤既有 `patt_seam_replay_uses_the_saved_snapshot_and_only_punches_the_roof`。碰撞工具 4 passed。332 项 Python 测试和 9 项 Slang CPU 测试通过（后者包含工作区既有地形材质候选测试）。
- `cargo check` 编译/复用全部 110 个 Slang 入口；生成结构由构建器更新。
- 真实 GPU 完整回放覆盖五类草花双 LOD、叶/苹果双 LOD、树龄重建、再结果与落果交接、显隐、旧路径及 GUI 调参，只有初始一次全局状态重置。最终回放日志 `re-flora-20260906-220811.448-549442.log`、正常 hidden/mute 启动日志 `re-flora-20260906-220657.444-548699.log` 均正常退出、无 ERROR/panic/VUID。
- 保存配置保持 C 开启、速度 ×3、阻尼 ×1、增益 ×1、姿态 10 Hz；GUI 和相机文件哈希检查未改变。

## 初步开销，不是性能验收

同机 RTX 3060 Ti、Release hidden/mute、2880×1620，固定场景 14,572 叶体素、17 苹果、9,541 高草、7,873 矮草及 60 特殊植物。各预热 600 帧、采样 2,000 帧，分析器按预先规则取 1,992 个完整样本。控制固定 ×1/×1/×1/5 Hz，不代表保存的 ×3/10 Hz 配置。

| 指标 | 旧共享叶场 | 逐叶 |
| --- | ---: | ---: |
| GPU 响应 pass 均值 | 12.35 μs | 20.75 μs |
| GPU 整帧均值 | 4.522 ms | 4.301 ms |
| CPU render.record 均值 | 1.745 ms | 2.921 ms |
| CPU 整帧均值（含等待） | 6.999 ms | 7.792 ms |
| 响应缓冲申请量 | 786,464 B | 6,291,488 B |

这是单次前后比较，桌面/GPU 未隔离，准备阶段还曾并行编译；不能用整帧均值下降声称加速。GPU 求解增加约 8.4 μs；CPU 记录阶段增加约 1.18 ms，当前逐帧身份重映射是后续应单独剖析的工作，不声称已经归因或消除了开销。保留全部长帧样本：逐叶 GPU pass 最大 600 μs、CPU 整帧最大 20.224 ms。先确认观感，再做稳定场景重复测量和必要优化。

固定场景有效状态共 16,810 个（两场 2,178 + 特殊植物 60 + 叶片 14,572）；80 B/状态，缓冲按容量取整并含输入和双输出，因此不是有效状态字节数乘一即可。记录申请量只有响应缓冲，不含 CPU 身份表/实例镜像、阴影成员引用或整个进程显存。

原始日志保存在 `target/individual-leaf-response-evidence/`，分析工具为 `scripts/analyze_vegetation_response_bench.py`。本次工作区另有地形材质候选，保留且不包含在本功能提交中；上述本机端到端测量运行的是包含该候选的工作区，不冒充纯净提交的独立验收。
