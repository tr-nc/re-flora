# Sustained local leaf flutter

## Corrected requirement and cause

The user means local back-and-forth leaf motion about its attachment, including
under steady wind, not a static lateral displacement and not unlimited rotation.
The previous torsion solver approached a fixed projected-torque equilibrium.
Both CPU and GPU tests explicitly required it to settle. Increasing the
displacement slider therefore only enlarged that resting offset.

The corrected regression first failed with continuous_variation=0.00000.
The final model uses smooth seeded local forcing, gated by the existing sampled
wind pressure, followed by the existing damped mechanical state. This is bounded,
deterministic, non-periodically repeating motion, not random position assignment.
No global wind field, emitter, audio driver or per-frame texture is introduced.
Wind removal or zero strength removes excitation and lets motion decay.

## Model boundary

The distinction between local flutter and whole-branch buffeting is supported by
[Tadrist et al., Foliage motion under wind, from leaf flutter to branch buffeting](https://pmc.ncbi.nlm.nih.gov/articles/PMC6000177/).
Their wind-tunnel study is not evidence that every leaf flutters at every wind
speed. This implementation is an art-directed proxy, not a calibrated
fluid-structure simulation: two smoothly interpolated hash-noise bands provide
local forcing from shared world seconds and a stable per-leaf seed.
The same authoritative GPU torsion state and held-angle publication drive
position and optical turning; the world wind and overall response are unchanged.

## Controls

Flora → Leaves → Wind Motion:

- Local Flutter Strength: strength of wind-powered local excitation; requires
  inertial response.
- Local Flutter Amplitude (voxels): local excursion envelope, 0–5. The saved ID
  leaf_local_displacement_voxels is unchanged. Dragging amplitude still rescales
  the current animated pose, but no longer selects a wind-loaded resting offset.
- Overall Wind Offset: independent whole-leaf translation. Set it to zero to
  inspect local flutter alone. Audio and grass are unaffected.

The startup amplitude and all user config values are preserved. No GPU ABI
change; the GUI descriptor label is regenerated by cargo check.

  reversals in the measured tail, 60/120 Hz state difference <= 0.00052702 rad.

These are deterministic motion-contract checks, not subjective animation or
performance acceptance.
