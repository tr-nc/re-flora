最终技术选型

继续 raster + compute/software voxel RT

这是和现有 renderer 最贴合、可渐进交付且最容易做确定性验证的路径。现成的 Contree 负责快速找到 surface，权威 dense voxel atlas 负责精确穿越 Glass medium；无需引入 Vulkan/DXR hardware RT、BLAS/TLAS 或 ray query。

有条件可发布

Glass 不是一个材质 if 分支

它跨越体素 ABI、存档 schema、first-hit query、composition 顺序、direct/local shadow、 DDGI visibility 与 probe relocation。只有这些语义成组一致，才能称为 production-ready。

首版产品契约

承诺
  • Air + 一种均匀 smooth Glass。
  • 实验阶段复用 VOXEL_TYPE_SAND（ID 3），不占新编码。
  • 只在专用 Glass test scene / feature flag 下启用，不进入普通 Sand 内容或正式存档。
  • 精确 entry/exit、Snell、dielectric Fresnel、TIR。
  • 按实际世界空间路径长度做 Beer-Lambert。
  • face-connected 同材质 Glass 是连续 medium。
  • 有界、确定性的 secondary path。
近似但明确
  • raster opaque 内容优先 screen-space 查询。
  • screen miss 回退 voxel world query 或 sky/environment。
  • DDGI 使用同方向低频 transmission，不折弯 probe ray。
  • direct sun 首版不产生 Glass shadow。
首版不承诺
  • 硬件 RT 与统一 raster secondary visibility。
  • 粗糙玻璃、色散、多 IOR 嵌套介质。
  • specular caustics。
  • 玻璃前后多层 particle/droplet 的完整排序与折射。
  • 任意非体素对象的离屏 reflection/refraction。
Go / No-Go：建议进入 Phase 0–1。不要直接从现有 terrarium glass prototype 改名上线；先建立 VoxelMaterial 和 SceneQuery 两个深模块，再接视觉路径。

当前项目进度与真实缺口

本表来自对 main@400794af 的代码与 release hidden run 复审。现有系统已经具备 软件 voxel RT 的主要地基，但还没有通用 Glass material、medium traversal 或可达的 Glass resolve。

production 引擎与论文：能借什么，不能借什么

来源可迁移的生产经验不能据此宣称
Unreal Lumen screen trace 先行、可靠 world representation fallback；质量档、覆盖限制与 profiler scope 是产品契约。 Lumen software RT 没有替 Re: Flora 解决 voxel thick Glass 的 entry/exit、Beer 或 DDGI transport。
Godot SDFGI raster + software grid/SDF traversal + probe GI 能生产化；cascade、ray count、history 与 half-res 需要显式档位。 SDF first hit 默认仍是 opaque visibility，不会自动获得 dielectric medium semantics。
DDGI 2019 / Production DDGI 2021 irradiance + directional hit-distance moments、visibility-aware interpolation、relocation、classification、cascades 与 temporal control。 论文没有定义“折射 probe ray 后如何仍保持原方向 moments 正确”的 Glass contract。
RTXGI-DDGI SDK 明确由应用负责 ray radiance/hit distance，SDK 负责 blend、relocation 与 classification；这证明 query backend 可以自定义。 其 sample 使用 hardware TLAS，也只示范 alpha-mask ignore；不应把 hardware 实现依赖带进本项目。
PBRT v4 Snell、精确 dielectric Fresnel、TIR 和 smooth dielectric 是首版数学 reference。 离线 path tracer 的无界递归/采样预算不能直接照搬到实时 compute。
glTF KHR_materials_volume surface transmission 与 volume attenuation 分离；closed boundary；world-space Beer distance；ray tracer 使用真实 path length。 raster thickness texture 只是 lossy estimate，不适合已有精确 atlas 的 voxel Glass。
Vulkan PPLL OIT primary pixel 的多个 raster fragment 可以存储、排序，并设置明确的层数/内存上限。 OIT 只拥有当前视图 rasterized fragments，不能提供离屏或被遮挡的 secondary visibility。
关键推断：screen-space-first + world-space fallback 是成熟的 production pattern； 但 Re: Flora 的 world-space truth 只覆盖 voxel/sky。首版应诚实记录 raster-only flora/object 的离屏缺失， 不能用 OIT、sorting 或 DDGI 模糊这个边界。

推荐渲染架构

Pass 顺序

1Voxel primary query — Glass 不作为 opaque 终点；同时输出 first opaque 与 nearest GlassFront event。
↓
2Raster opaque pass — depth prefill 使用 first opaque voxel depth，让 Glass 后的 flora/object 真正被绘制。
↓
3Opaque scene resolve — voxel + raster + sky/cloud 合成 UnifiedOpaqueHDR，保留 nearest opaque depth 与 provenance。
↓
4Glass resolve — 读取 opaque HDR/depth 与 GlassFront；world-space voxel query + validated screen-space raster sample；写独立 RGBA16F target。
↓
5Camera-space effects — 明确支持的 raster translucency、god rays/lens flare，再 tone map、dither 与 final output。

不能在同一个 HDR image 上一边读取 opaque scene 一边写 Glass，必须 ping-pong。当前 raster target 是 RGBA8 UNORM；如果希望玻璃后/反射中的 emissive 与 local-light highlight 不被提前裁掉， Phase 2 必须用 capture 与带宽实测决定是否把 opaque raster target 提升为 RGBA16F。

深模块 1：VoxelMaterial

用一份权威声明生成或校验 Rust/Slang mirror，取代散落的 type != Empty 与 per-type if 链：

VoxelMaterial {
  id: VOXEL_TYPE_SAND, // 3, experiment only
  surface_class: Dielectric,
  collision_solid: true,
  water_solid: true,
  terrain_support: ExplicitPolicy,
  probe_relocation_solid: true,
  blocks_ddgi_visibility: false,
  direct_shadow: SkipV1,
  local_shadow: OpticalTransmittance,
  soil_state_allowed: false,
  optical: { ior, sigma_a_rgb, roughness: 0 }
}

实验 flag 关闭时，ID 3 保持 Sand 的现有 soil、smoothing、footstep、backpack、acoustic 和 material 行为；开启时才由专用实验 policy 把 ID 3 解释为 dielectric。实验场景不得运行会放置 Sand 的 environment-lighting donor case，也不得写入正式 save。Glass voxel 的 moisture/fertility 高 nibble 必须规范为 0。IOR、attenuation color/distance 与未来 roughness 属于 material table，不占 per-voxel soil-state bits。ID 8 的 Emissive collector 必须保持 exact-ID 行为。

为什么实验复用 Sand：当前默认 terrain 初始化只产出 Dirt 与 Rock，Sand 没有默认 authored content；复用 ID 3 因而不需要新增 material ID、扩 edit stats 或升级 schema。但 Sand 并非代码层死类型： soil/moisture、smoothing、footstep、backpack、acoustics 和部分测试仍识别它，所以 feature-OFF 回归和 test-scene 隔离是硬 gate，不能把这次实验解释为正式重命名 Sand。

深模块 2：SceneQuery

trace_first_surface(ray, mask)
  -> SurfaceHit | Miss

walk_voxel_media(ray, starting_medium, event_budget)
  -> ordered InterfaceEvent | MediumSegment | OpaqueHit | Miss

trace_radiance(ray, path_budget, fallback_policy)
  -> RadianceResult + QueryDiagnostics

trace_segment_transmittance(origin, target, policy)
  -> RGB transmittance + TerminationReason
  1. 现有 Contree 找 first surface / chunk entry，保留 sparse surface acceleration。
  2. 进入 Glass 后，用 authoritative dense atlas 做 Amanatides–Woo style cell-boundary DDA。
  3. DDA 返回 axis-aligned geometric face normal、from/to material、cell 与 world-space segment length。
  4. Glass → Glass 只累计距离；Glass ↔ Air 或 Glass → Opaque 才是 interface event。
  5. camera 所在 atlas cell 初始化 current medium，不能靠 shading normal 猜 entering/exiting。
  6. epsilon、corner tie、chunk seam、world boundary 和预算终止都封装在模块内。
不建设假 seam：没有 TLAS/BLAS adapter，也不预留 hardware ray-query 接口。 当前唯一 truth backend 就是 Contree + dense atlas；未来真有第二个实现时再抽象 adapter。

介电光学与有界路径策略

每个真实界面

  1. 用 DDA face normal 判定 incident/outgoing medium。
  2. 使用 eta_i / eta_t 求 Snell refraction。
  3. 计算 exact unpolarized dielectric Fresnel F。
  4. 无折射解时进入 TIR，F = 1。
  5. medium segment 乘 exp(-sigma_a * distance_world)。
  6. Opaque 命中终止 transmitted branch；Miss 走 sky/environment。

作者友好的 Beer 参数

sigma_a = -log(attenuation_color)
          / attenuation_distance

T(distance) = exp(-sigma_a * distance)
            = attenuation_color
              ^ (distance / attenuation_distance)

attenuation distance 是世界空间长度；一 voxel 厚斜入射路径可以明显长于 voxel edge。

确定性 top-K，而不是无界递归

控制项初始工程上限说明
active paths4按 RGB luminance throughput 排序，稳定 tie-break。
interface events8Glass slab、air gap 与有限 TIR loop 可覆盖；最终由 reference scenes 决定。

reference mode 使用 CPU double precision 或离线高预算路径，对 interface sequence、exit position、 Fresnel/TIR、Beer 与总能量做误差比较。它属于开发/离线 gate，不进入普通快速 cargo test 的 GPU 长时路径。

Screen-space sample 的有效性

  • projected UV 在 viewport 内。
  • sampled opaque depth 位于 Glass exit 之后，并通过 thickness/depth tolerance。
  • provenance 是允许被折射的 opaque raster 或已合成 opaque voxel。
  • 失败时回退 world-space voxel hit / sky；不得拉伸边缘 texel。
  • debug view 区分 screen-hit、voxel-fallback、sky-fallback、rejected-depth。

DDGI：保持 radiance 与 distance 的方向语义一致

DDGI 一条 probe ray 同时写原始方向上的 radiance sample 和 signed hit distance；后者会过滤成 moments 并参与 receiver visibility。如果 probe ray 在 Glass 内真实折弯，却把折线路径末端距离写回原方向， visibility 就会把错误路径当成原方向 blocker。现有论文与 RTXGI 没有为这种做法提供 contract。

首版策略：主视图 Glass 做真实折射；DDGI probe Glass 做同方向低频 transmission， 累计界面 Fresnel 与 Beer，但保持 ray direction 不变。distance 记录该原方向的 first opaque hit 或 far。 
direction = original_probe_direction
throughput = 1

for transitions along direction:
  Air -> Glass: throughput *= (1 - Fresnel)
  Glass segment: throughput *= Beer(sigma_a, distance)
  Glass -> Air: throughput *= (1 - Fresnel)
  Opaque hit:
    radiance = throughput * shade_opaque_hit()
    distance = straight_distance_to_opaque
  Miss:
    radiance = throughput * sky(direction)
    distance = far
DDGI 子系统Glass 首版语义必须联动的实现
Probe radiance trace同方向穿透，累计 Fresnel/Beer。ddgi_probe_trace.slang 不再把 Glass 当 opaque shading hit。
Moment distancefirst opaque 或 far；不记录 Glass front。与 probe radiance 使用同一 traversal event stream。
Exact visibilityGlass 是 non-blocker。visibility pack 由 semantic bit 构建，而不是 raw non-empty。
Empty-block accelerationblock 只在含 visibility blocker 时 occupied。否则 coarse skip 会把 Glass 偷偷恢复为 opaque。
Probe relocationGlass 仍为 solid。避免 probe 落入当前没有 medium state 的玻璃体内。
Probe classification使用 relocation/opaque-aware fixed-ray semantics。Glass wall 两侧单独 capture actual position、clearance、valid count。
Glass surface shading不作 tinted Lambertian receiver。专用 Glass resolve 负责 specular appearance；DDGI 只作低频 fallback。

Revision / temporal policy

  • 放置/删除 Glass、改变 blocks_ddgi_visibility：geometry revision，重建 semantic visibility bits，并触发 relocation/recovery。
  • 只改变 IOR、attenuation color/distance：radiance/material revision；visibility history 原则上可保留。
  • Opaque ↔ Dielectric 改类：geometry + radiance 都更新。
  • immutable DDGI lighting snapshot 必须包含 Glass material revision，禁止一次 sweep 混用两套 optical 参数。
  • Glass topology 可能打开远距离可见性；首版宁可 global transport refresh，不要未经证明地假设局部 edit bounds 足够。

Direct sun 与 local lights

Direct sun v1

Glass 不写 terrain opaque VSM depth，明确“无 Glass shadow / 无 caustics”。后续若需要 colored shadow，增加独立 light-space RGB optical-transmittance；不能把它命名为 caustics。

Local lights

把已有 finite-segment binary visibility 收敛到 trace_segment_transmittance()：Opaque 返回 0，Glass 累积 RGB Fresnel/Beer，无 blocker 保留 T。

分阶段实施计划

每个阶段都先通过自己的 gate 并提交，再开始下一阶段；实验不改 schema，不把 material policy、query、pass 重排和 DDGI 一次塞进一个不可审查的大改。

0 Experimental material policy

交付：在专用 feature/test scene 下把 Sand ID 3 解释为 Glass；不新增 ID、不扩 stats、不升 schema；明确普通 Sand consumer 隔离、save 禁止和 soil-state canonicalization。

Gate：feature OFF 时 Sand/soil/smoothing/footstep/backpack/acoustic 行为不变；feature ON 只能进入可重建 test scene；ID 8 Emissive provider 与全部旧 persistence fixtures 不回归。

主要文件：voxel_types.slang、builder/plain、terrain_persistence.rs、backpack/particles/acoustics。

Gate：single slab、connected cells、air gap、opaque contact、chunk seam、corner tie、TIR 两侧与 Beer 单调性全通过；默认场景 exhaustion=0。

主要文件：新增 scene_query.slang/voxel_medium_walk.slang；小幅接入 tracer.slang。

2 Opaque-first hybrid composition

交付：UnifiedOpaqueHDR ping-pong；opaque provenance/depth；独立 Glass resolve；screen validity；voxel/sky fallback；debug views。

Gate：Glass 后 flora 不被 prefill 剔除；Glass 前 foreground 保持；edge/disocclusion/resize/cut 稳定；无 read-write feedback；HDR highlights 不早裁。

3 DDGI / shadows / temporal hardening

交付：semantic DDGI visibility bits；straight-through probe Glass；relocation tests；local RGB transmittance；sun policy；material revision/recovery。

Gate：窗两侧 radiance/distance capture；visibility bits 与 probe trace 无冲突；relocation deterministic；optical edits 收敛且不重建无关 geometry。

主要文件：ddgi_probe_trace、visibility pack/DDA、relocation/classification、local lighting、shadow path。

4 Performance / release hardening

交付：0/10/25/50% coverage scenarios；GPU scopes/counters；memory report；forced fallback screenshots；documented product limitations。

Gate：Glass OFF 满足现有 regression budgets；Glass ON 使用同 GPU、camera、resolution、DDGI-ready state 做 A/B/B/A；non-finite/validation/exhaustion 直接 RED。

备注：25% coverage +1.0 ms median / +1.5 ms p95 只是首轮规划目标，不是实测或 ship budget。

首三个可审查提交

  1. Policy commit：Sand ID 3 的实验解释、普通 Sand 隔离、不保存 guard 与 tests；feature OFF 图像不变。
  2. Query commit：DDA + CPU reference + debug-only interface capture；不接 production resolve。
  3. Visual slice commit：voxel-only Glass resolve + fixed scenes；raster fallback 与 DDGI 保持 feature flag 后续进入。

这样每一步都能独立回滚、bisect、review 和测量。

主要风险、决策与停止线

风险症状控制停止线
语义分叉probe 看穿，exact visibility 却阻挡；local/sun 行为不同。VoxelMaterial policy + shared query + cross-consumer tests。任何 consumer 仍以 raw non-empty 隐式决定 Glass。
Raster visibility 缺失屏幕边缘拉伸、离屏 flora 消失。validated sample + provenance debug + voxel/sky fallback。文档或 UI 宣称“完整 secondary visibility”。
Depth prefill 错序Glass 后 opaque object 从未被 rasterized。first opaque depth 驱动 prefill；GlassFront 独立输出。Glass front 进入 opaque terrain depth。
无界路径成本TIR/多界面时 p95 爆炸。deterministic top-K、query/event budget、exhaustion counter。默认 authored scenes 出现非零 exhaustion。
实验语义泄漏普通 Sand、soil/smoothing 或 save 被当成 Glass。专用 feature/test scene、Sand consumer 隔离、save fail-closed、feature-OFF fixtures。任何正式存档含实验 Glass，或正常路径中的 ID 3 改变行为。
DDGI temporal 污染参数编辑后 ghost、mixed revision、错误 publication。material revision 入 immutable snapshot；按变更类别失效 history。一次 sweep 混用两套 Glass optical 参数。
带宽回归无 Glass 场景也分配/清空 full-res targets。0% fast path、lazy resources、lifetime aliasing、release capture。Glass OFF 超出现有 perf gate。

明确否决的方案

  • 硬件 RT/TLAS/BLAS/ray query：已超出技术选型，不列作“以后兜底”。
  • Glass = alpha blend：没有 exit、路径长度、TIR 或正确 secondary visibility。
  • 只复用 Contree surface hit 猜厚度：surface shell 不包含连续 medium 内部 truth。
  • 直接启用 terrarium Glass：是 analytic/prototype path，当前不可达且不具备 voxel topology semantics。
  • 让 DDGI probe ray 真折射并写原方向 moments：radiance/distance 方向 contract 不一致。
  • 用 OIT 解决 secondary visibility：OIT 只排序 current-view fragments。
