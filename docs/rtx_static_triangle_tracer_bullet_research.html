明确 verdict 与风险边界

NO-GO for order-of-magnitude

global opaque exposed-face triangle BLAS 的最好正确结果只有 dense 的 1.309×，sparse/shell 明显倒退。AABB exact-confirm 正确但同样没有更高上限。不要把这个 bullet 扩成永久第二套 terrain lifecycle。

  • 只测 RTX 3060 Ti / 580.159.04；没有跨厂商或跨世代。
  • 使用 compute ray query，不是 ray-tracing pipeline/SBT。
  • 没有 atlas/material、lighting、secondary-ray consumer 或 production frame fraction。
  • 没有 edit/refit/rebuild/streaming/publication/fallback；这是刻意边界。
  • 精确共享边的 voxel tie-break 没有跨实现唯一标准；吞吐 rays 避开多解，显式非共面 boundary/grazing rays 通过。

若未来继续，先指定一个占帧足够大的 production ray consumer；对于纯 any-hit shadow，再单独测 terminate-on-first。不能拿本次 closest-hit 或不正确的 any-hit identity 外推整帧。
