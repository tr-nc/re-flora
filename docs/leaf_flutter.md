# 轴对齐树叶的局部抖动

Debug → Flora → Leaves → Flight & Lighting → `Local Flutter (0 = original)`，默认 1，范围 0–2。设为 0 可对比原效果。保持原有整体风响应。

每片叶子增加一个有惯性、有阻尼的内部铰链角。局部风驱动力与风速平方相关，叠加按叶子种子区分的连续小尺度激励；无风时激励归零，运动衰减。同一个角度同时驱动中心的小幅平移和内部光学法线，并沿用已有的离散姿态发布节奏。

**几何顶点偏移不旋转，立方体始终轴对齐。每片叶子在每帧只计算一个 RGB，各个顶点及各个面共用它。** 内部法线只决定观察到的正反面混合、太阳入射角和透射贡献，不用于几何变换、阴影射线偏置或 DDGI 缓存方向。

这是物理启发的薄叶代理模型：角度与颜色有共同状态，避免独立的颜色闪烁器。未解析的湍动采用连续双频激励，风速单位、正反面色差和透射比例仍是美术标定，不代表完整气动或叶片光谱模型。环境光继续使用现有稳定的树冠缓存方向。研究依据见 [叶片朝向研究](research/leaf_orientation_flutter.md)。

## 验证

- `cargo fmt --check`、`cargo check`；Rust 测试 925 通过、2 忽略。
- `python3 scripts/run_slang_tests.py`：9 项通过，直接执行生产着色器函数，检查轻风持续响应、个体差异、无风衰减、法线及位移边界、光学变化与全黑输入。
- `RE_FLORA_VEGETATION_RESPONSE_VALIDATE=1` 隐藏静音 release 实机：叶片峰值角约 0.355 弧度，个体角差约 0.625 弧度，静风末态约 4e-8 弧度；保持姿态边界及原有响应验证通过。
- 同一 blacky 近景分别捕获关闭和默认模式，各 120 个连续帧，每 3 帧保存 RGB。检查实际截图中的局部位移与颜色变化；本地回放为 `target/leaf-flutter/review.html`。风场 B 在这个场景启动约 20 秒后才有明显来流，捕获前预热 3600 帧。


状态从 80 增至 112 字节；当前 32768 容量的两个输出缓冲合计增加 2 MiB。尚未完成叶片性能专项基准。视觉候选与性能验收分开。

## 脱落叶子粒子

树叶和落叶共同调用 `leaf_lighting.slang::shadeLeafWithEnvironment`，后者统一调用 `leaf_flutter.slang::leafOpticalColor`。共享太阳光、正反面反射/透射和观察方向逻辑；各自只提供位置、基色、环境光、遮挡和内部法线。

脱落叶子固定使用下节的新飞行模型和模拟姿态光学法线，几何固定为 screen-facing quad。每个粒子只输出一个 RGB；白色叶片纹理不引入颜色变化。非下落的叶色粒子仍保留原有运动方向代理法线，避免改变采集等其他运动路径。

显式的粒子光学标记区分叶片与共用纹理层的水滴/地形粒子；蝴蝶、水滴及地形粒子保留原着色。脱落叶片光学始终启用，不受挂树叶 `Local Flutter = 0` 限制。共享光学接入时实例布局已从 36 字节增加为 52 字节。

## 脱落叶飞行：固定新物理、姿态光学与 screen-facing quad

用户已结束这轮 A/B 探索：**两个落叶 checkbox 及其模式切换逻辑均已删除**。不再有旧落叶物理模式，也不再有旋转薄片画法。Debug → Flora → Leaves → Flight & Lighting 只保留原有叶片光学/局部抖动参数，没有另换隐藏开关或 CLI 模式。

连续姿态、相对来流与角速度共同影响下落、滑移及翻转；光学读取同一模拟四元数，但几何始终是面向镜头的正方形，不是世界轴对齐立方体。内部法线仍会旋转，专用于 `leafParticleOpticalNormal`，不会旋转 quad 的顶点。没有改成相机光学法线或速度代理，没有复制光学公式，也没有独立随机颜色。

billboard 轮廓不反映叶片物理迎角，整叶 RGB 则由模拟姿态驱动，是明确的风格化几何代理，不宣称几何投影严格物理正确。

只有 `Leaf + Falling` 粒子固定使用新飞行模型。仍挂树上的 cube 保持 axis-aligned；采集粒子、水、地形和蝴蝶不参与。为其他 kind/motion 保留原共享运动分支，不能因删除落叶 A 模式而顺便改变它们。落叶没有几何正反面材质分支，仍沿用白色纹理与共享叶光学函数；删除旋转画法后，主粒子管线恢复原来的 BACK 剔除，quad 始终朝向镜头。

实现与研究见 [自由叶片研究](research/fallen_leaf_flight.md)、`src/particles/leaf_flight.rs`。初版参数是游戏标定：重力 `0.22` 世界单位/s²，风场到世界速度系数 `0.035`，边缘/正迎风二次阻力系数 `7/70`，平移/旋转升力系数 `45/0.65`，有效俯仰力矩系数 `900`。旋转升力随相对来流速度与角速度耦合，不添加独立位移或颜色噪声。尺寸按等面密度薄片缩放角响应；初始姿态/角动量由已有粒子身份和种子确定，不改变发射器 RNG 序列。

机械积分为 `120 Hz` 固定步长，四元数每步归一化，升力用速度旋转避免虚增相对动能。角阻尼为 `0.4 + 0.15|ω|`；极端输入保护：角速度最多 `12 rad/s`、映射空气速度最多 `0.75` 世界单位/s、相对速度最多 `2` 世界单位/s、单帧机械追赶最多 `0.25 s`。超长停顿仍推进原年龄/销毁判定，机械轨迹不作完整补算。普通测试未触及角速度上限。

**模拟与上屏节奏分离**：保留既有粒子 world-tick 两桶发布节奏；默认 World Tick 为 `0.05 s`，全场每 tick 发布一桶，每片约 `10 Hz`。两次发布间保持位置、速度和光学四元数，不插值。物理仍逐帧调用原 `120 Hz` 积分器；删除开关没有改积分器、风场或寿命/数量权威。改变 World Tick 不得重置物理状态。相机和环境照明仍实时响应，只有姿态驱动的光学输入随显示姿态保持。

每槽位增加 32 字节 CPU 角状态，16,384 容量合计 512 KiB；没有新增 GPU 实例字段。纹理索引 bit 30 标记脱落叶的模拟姿态光学输入（不是运行模式开关）；bit 29 的旋转绘制标记已删除，bit 31 保留原 sprite flip。原 `leaf_optics` 四分量承载脱落叶四元数，其他叶色粒子仍承载法线/标记，实例仍为 52 字节。将来整合蝴蝶分支时必须语义协调这套打包约定。

CPU 检查覆盖固定姿态下降、倾斜镜像滑移、旋转升力、20–240 FPS 恒定风轨迹、120 秒稳定性、极端阵风/停顿、默认无条件启用、槽位复用、寿命下沉/销毁及其他粒子隔离；Slang 生产函数检查 81 个光学姿态与 3 个相机基底，验证几何始终 screen-facing、各顶点共用随姿态变化的 RGB。[实机与连续帧交接](fallen_leaf_flight_validation.md) 保留历史 A/B 研究及最新固定模式验证。若将来重做旋转绘制，可参考历史提交 `4c7bf3b2`，无需重做物理和光学；不为此保留禁用代码。
