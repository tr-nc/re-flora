# 轴对齐树叶的局部抖动

Debug → Flora → Leaves → `Local Flutter (0 = original)`，默认 1，范围 0–2。设为 0 可对比原效果。保持原有整体风响应。

每片叶子增加一个有惯性、有阻尼的内部铰链角。局部风驱动力与风速平方相关，叠加按叶子种子区分的连续小尺度激励；无风时激励归零，运动衰减。同一个角度同时驱动中心的小幅平移和内部光学法线，并沿用已有的离散姿态发布节奏。

**几何顶点偏移不旋转，立方体始终轴对齐。每片叶子在每帧只计算一个 RGB，各个顶点及各个面共用它。** 内部法线只决定观察到的正反面混合、太阳入射角和透射贡献，不用于几何变换、阴影射线偏置或 DDGI 缓存方向。

这是物理启发的薄叶代理模型：角度与颜色有共同状态，避免独立的颜色闪烁器。未解析的湍动采用连续双频激励，风速单位、正反面色差和透射比例仍是美术标定，不代表完整气动或叶片光谱模型。环境光继续使用现有稳定的树冠缓存方向。研究依据见 [叶片朝向研究](research/leaf_orientation_flutter.md)。

## 验证

- `cargo fmt --check`、`cargo check`；Rust 测试 925 通过、2 忽略。
- `python3 scripts/run_slang_tests.py`：9 项通过，直接执行生产着色器函数，检查轻风持续响应、个体差异、无风衰减、法线及位移边界、光学变化与全黑输入。
- `RE_FLORA_VEGETATION_RESPONSE_VALIDATE=1` 隐藏静音 release 实机：叶片峰值角约 0.355 弧度，个体角差约 0.625 弧度，静风末态约 4e-8 弧度；保持姿态边界及原有响应验证通过。
- 同一 blacky 近景分别捕获关闭和默认模式，各 120 个连续帧，每 3 帧保存 RGB。检查实际截图中的局部位移与颜色变化；本地回放为 `target/leaf-flutter/review.html`。风场 B 在这个场景启动约 20 秒后才有明显来流，捕获前预热 3600 帧。

复现截图：

```sh
RE_FLORA_LEAF_REVIEW=1 RE_FLORA_WIND_AB_SMOKE=1 flock --close /tmp/re-flora-summer-gpu.lock cargo run --release -- --hidden --mute --windowed --denoiser-bench blacky target/leaf-flutter/settled-new.toml --denoiser-bench-warmup-frames 3600 --denoiser-bench-frames 120
```

`RE_FLORA_LEAF_REVIEW` 只覆盖本次运行的强度，并启用密集关键帧，不写入 GUI 默认值。两次捕获未锁定模拟相位；回放用平均采样间隔，不能当作性能、精确运动时间或主观自然度的验收证明。

状态从 80 增至 112 字节；当前 32768 容量的两个输出缓冲合计增加 2 MiB。尚未完成叶片性能专项基准。视觉候选与性能验收分开。

## 脱落叶子粒子

树叶和落叶共同调用 `leaf_lighting.slang::shadeLeafWithEnvironment`，后者统一调用 `leaf_flutter.slang::leafOpticalColor`。共享太阳光、正反面反射/透射和观察方向逻辑；各自只提供位置、基色、环境光、遮挡和内部法线。

未勾选实验开关时，落叶保留基线运动方向代理法线，垂直分量加入 0.05 游戏速度单位偏置避免静止奇点。原有 billboard、粒子轨迹和纹理轮廓保持不变。每个粒子只输出一个 RGB；白色叶片纹理不引入颜色变化。

显式的粒子光学标记区分叶片与共用纹理层的水滴/地形粒子；蝴蝶、水滴及地形粒子保留原着色。A 模式下 `Local Flutter = 0` 同时关闭落叶的新着色；B 模式见下节。共享光学接入时实例布局已从 36 字节增加为 52 字节。

## 脱落薄片飞行 A/B

Debug → Flora → Leaves → `B: Fallen leaf plate flight (A/B experiment)`，默认不勾选。

- A：原落叶 billboard、噪声下落和运动方向代理光学法线。
- B：真正世界空间的正方形薄板，几何与光学共用模拟四元数；连续的姿态、相对来流与角速度共同影响下落、滑移及翻转。B 的真实姿态光学不受附着叶 `Local Flutter` 开关限制。

切换不清空或重新发射粒子，保留位置、速度、颜色、年龄及句柄；因此可实时比较，但不是倒带回放同一条轨迹。只有 `Leaf + Falling` 粒子使用薄片模型。仍挂树上的 cube 保持 axis-aligned；采集粒子、水、地形和蝴蝶不参与。薄板无背面剔除、无正反面材质分支，仍沿用白色纹理与共享叶光学函数。精确侧视时零厚度板会变细，这是几何投影而非剔除消失。

实现与研究见 [自由叶片研究](research/fallen_leaf_flight.md)、`src/particles/leaf_flight.rs`。初版参数是游戏标定：重力 `0.22` 世界单位/s²，风场到世界速度系数 `0.035`，边缘/正迎风二次阻力系数 `7/70`，平移/旋转升力系数 `45/0.65`，有效俯仰力矩系数 `900`。旋转升力随相对来流速度与角速度耦合，不添加独立位移或颜色噪声。尺寸按等面密度薄片缩放角响应；初始姿态/角动量由已有粒子身份和种子确定，不改变发射器 RNG 序列。

机械积分为 `120 Hz` 固定步长，四元数每步归一化，升力用速度旋转避免虚增相对动能。角阻尼为 `0.4 + 0.15|ω|`；极端输入保护：角速度最多 `12 rad/s`、映射空气速度最多 `0.75` 世界单位/s、相对速度最多 `2` 世界单位/s、单帧机械追赶最多 `0.25 s`。超长停顿仍推进原年龄/销毁判定，机械轨迹不作完整补算。普通测试未触及角速度上限。

**模拟与上屏节奏分离**：A/B 共用既有粒子 world-tick 两桶发布节奏；默认 World Tick 为 `0.05 s`，全场每 tick 发布一桶，每片约 `10 Hz`。两次发布间保持位置、速度代理和几何/光学四元数，不插值。B 物理仍逐帧调用原 `120 Hz` 积分器，A 物理仍保持原更新方式；改变 World Tick 或切换 checkbox 不得重置物理状态。相机和环境照明仍实时响应，只有姿态驱动的光学输入随显示姿态保持。

每槽位增加 32 字节 CPU 角状态，16,384 容量合计 512 KiB；没有新增 GPU 实例字段。纹理索引 bit 30 标记 B 薄片，原 `leaf_optics` 四分量在 B 中承载四元数，A 仍承载法线/标记，实例仍为 52 字节。将来整合蝴蝶分支时必须语义协调这两处打包约定。

候选的 CPU 检查已覆盖固定姿态下降、倾斜镜像滑移、旋转升力、20–240 FPS 恒定风轨迹、120 秒稳定性、极端阵风/停顿、开关保留、槽位复用、寿命下沉/销毁及其他粒子隔离；Slang 生产姿态函数通过 81 个姿态的等边/正交/法线一致性检查。[实机与连续帧交接](fallen_leaf_flight_validation.md) 记录已执行的隐藏 A/B、同进程切换和正常树冠发射；用户自然度认可及专项性能仍未验收。
