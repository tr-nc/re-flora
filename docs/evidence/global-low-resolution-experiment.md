# 全场景低分辨率实验

分支：`experiment/global-low-resolution`。这是直接替换渲染路径的实验分支，不提供原版/实验版运行时开关，不更改 main 的默认行为。

## 尺寸契约

原正常模式内部渲染为窗口宽高的 0.5；本分支固定为 0.125，最低尺寸为 1。也就是宽高各为原内部尺寸的 1/4，场景像素数为原来的 1/16。

例如：2560×1440 窗口，原内部 1280×720，新内部 320×180。场景按像素中心最近邻放大，后处理抖动以内部像素为坐标；窗口、UI 和文字尺寸不变。缩放窗口时重新计算场景尺寸。

## 模型路径

- 花头、树上/落地苹果、落叶和蝴蝶改为普通索引三角形绘制。姿态、蝴蝶动画、材质、环境光和模拟所有权保留。
- 删除逐模型颜色/深度图集、模型烘焙和逐帧 tile compute pipeline，以及草的 raster atlas 批处理运行路径。
- 草和花茎不再进行模型网格采样和显示深度重建；方形 Color Band 保留连续几何、平坦颜色和已有生长/风响应。解析几何选择仍是几何选项，不是逐模型像素化开关。
- 旧保存文件的分辨率、视角数量和模型像素化字段仍可读入，但不影响此分支渲染，不出现在 Debug 控件或搜索结果中。少量旧 shader logical name 和测试专用纯逻辑代码保留，不代表仍运行图集路径。
- 用户的 `config/gui.toml` 和 `config/camera_snapshots.toml` 保持实验开始时的字节内容，未纳入任务提交。

## 验证

日志：`target/global-low-resolution/`。

- `cargo fmt --check`、`cargo check`、`cargo build --release`。
- Rust 主程序测试：1328 通过，3 忽略；Vulkan 库测试：57 通过；Slang CPU 测试：34 通过。
- 隐藏静音 Release 启动、authored flora 场景、开启同步验证的窗口连续 resize：退出均为 `failures=0`，检索未发现 ERROR、VUID 或同步 hazard。
- resize 实测：1408×792 → 176×99；1024×768 → 128×96；1280×720 → 160×90。
- 实际截图：`target/global-low-resolution/global-scene.png`；已检查场景像素块与原生 UI 的分离。没有自动启动可见游戏。

这是视觉探索候选，不是性能验收。尚未做受控前后性能比较，也未完成用户对相机运动、远处细节及所有模型外观的人工验收。旧 atlas 专用验证脚本和历史性能结果不用于证明此分支的效果或性能。
