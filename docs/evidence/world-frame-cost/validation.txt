Statistics
- Durations are microseconds in raw samples/data.json, milliseconds in the HTML.
- Same-named GPU scopes within one frame are summed (not overwritten).
- Repeated GPU frame IDs are deduplicated. Conditional absent scopes count as zero
  for amortized means; full leaf rankings use complete-capacity captures only.
- Parent GPU scopes excluded from the leaf ranking: frame.render, tracer.render,
  graphics.pass, tracer.shadow_prepass. CPU waits and GPU scopes are not added.
- FPS derives from frame-count/time differences, not inverse GPU time.
- Main aggregate uses pooled per-frame samples; displayed FPS is mean run throughput.
- Raw samples (*.samples.json.gz), native log excerpts and telemetry are committed.
- Remaining CPU unclassified residual is explicitly reported, not guessed.
