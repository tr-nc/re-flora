# 蜜蜂与两种小鸟：网页模型交付

## 范围与入口

用户取消小狗，其余保持：仅在现有后处理预览台注册 `bee`、`sparrow`、`swallow`。没有另开 HTML demo，没有发布动物 GLB / 游戏模型、改 native 注册表或实现 AI／飞行行为。

`models/animal-geometry.mjs` 提供原创确定性三角形配方和绝对时间姿态，`models/animals.js` 只做 Three.js 生命周期适配。共用 `models/index.js`、声明式参数、相机／动画时间轴与原有 source→ID→几何覆盖→颜色补点管线。

| 模型 | 可辨认形态 | 三角形 |
| --- | --- | ---: |
| 蜜蜂 | 琥珀色七段腹部条纹、六足、双触角、两对浅色翅 | 1994 |
| 圆身麻雀风格 | 宽圆身体、浅胸、短喙、棕色翼斑、短扇尾 | 1150 |
| 长尾燕子风格 | 较细蓝背、浅胸赤褐喉、尖长翼、分叉长尾 | 1146 |

鸟类是风格化轮廓，不宣称准确物种重建。两鸟共用生成骨架但几何比例、翼形、尾部拓扑不同，不仅是改 palette。所有配方为此任务写的原创代码，无新增第三方模型／纹理／授权依赖。

## 动画与材质边界

- 静止姿态和拍翼展示两个片段；`sample(time, clip)` 可任意跳转，左右翼镜像，整周期回到相同姿态。一个共用时间轴驱动 source/pixel；没有第二个 requestAnimationFrame 或累积 Euler 旋转。
- 模型大小、翅长、拍翼幅度、五种颜色可调；仅拍翼片段响应幅度。控件不创建新几何／材质。静止姿态确实静止。
- 身体（含头足尾）／左翅／右翅各一个 repair ID，不把两侧翅作为可随意跨空隙连线的同一组。
- 蜜蜂翅是**不透明浅色低模**；当前覆盖和 ID 协议不支持 alpha 透明，未绕过它引入半透明贴片。鸟的眼高光、腿足、尾尖也都是几何。
- 默认 48²，沿用画布分辨率范围与透明 PNG 导出。固定 span=4.6 包住最大参数与拍翼；不是姿态自适应撑满。
- 动作仅用于查看细部稳定性，不是空气动力学或真实鸟类飞行：停栖足在拍翼片段未收起，也没有身体从栖息到水平飞行的完整骨骼过渡。

## 验证

- `node --test experiments/model-preview/tests/*.test.mjs`：34 passed。动物新增检查确定性、所有顶点有限、非退化三角形、有效索引、三组、蜜蜂六足四翅、两种尾形和周期／镜像／静止姿态。
- `tests/animals-browser.cjs`：3 个模型，75 个姿态，19,614 个中心采样 RGBA 原样保留。覆盖 8/32/64/128px、正交／透视、前／后／侧，保守覆盖开关、颜色／尺度／翅长、时间轴跳转／播放／逐帧／复位、PNG 48² 透明角、390px 布局。
- 32 个拍翼相位、最大参数的实际世界顶点距取景中心最大值：蜜蜂 `2.079213`、麻雀 `1.711164`、燕子 `2.249090`，均小于半 span `2.3`。
- 反复模型参数调整无 GPU 几何／纹理增长；预热一次共用 flower depth target 后，动物和带纹理花朵反复切换资源计数一致。该 depth target 由 pipeline 持有到页面销毁，不能误报为模型泄漏，也不能忽略每次切换持续增长。
- page / console / request errors 为空，所有请求本机同源。实际 agent-browser 检查三种模型、燕子背面；查看总览和拍翼截图确认轮廓差异。无可见游戏启动。

### 可见限制，未隐藏

8px 的燕子前／后视在两种投影中有四个姿态**一个中心样本都没有**；共用保守覆盖仍补出 14 个像素。测试明确记录 `centerMisses`，检查最终非空并继续严格检查其余原始 RGBA，不能把“中心采样永不消失”当作新算法保证。关闭保守覆盖时薄部件／这种极低分辨率模型仍可能消失，这是保留旧模式的真实 A/B。小眼高光、足趾和尾叉低分辨率下会合并；没有模型专用加宽／时间抗锯齿补丁。

证据路径：`target/animal-preview-review/{summary.json,browser.log,contact-sheet.png,*-rest.png,*-flight.png,swallow-back.png,mobile.png}`；Node 日志 `target/animal-tests.log`。截图不提交，测试可复现。SwiftShader 浏览器运行是正确性／视觉证据，不是游戏 Release 性能测试；本步骤未修改 Rust／shader／native 资产。
