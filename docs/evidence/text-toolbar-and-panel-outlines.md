# Text toolbar and saved panel outlines

## Behavior

- Bottom toolbar is text-only: tool label plus a small shortcut hint, no images, icon drawings,
  category tiles or per-item/keycap borders. Hover/focus underlines the label; selection stays
  gold with a persistent underline. Both states retain the same layout and pointer targets.
- One borderless translucent background separates text from the game. The bar measures the
  active fonts and wraps on narrow windows rather than hiding tools or reducing text size.
- Existing slot IDs, click-to-toggle selection, tooltips, keyboard shortcuts, cursor-mode input
  gating and unavailable-tool gating are preserved. Icon loading/texture ownership were removed;
  existing source artwork was not deleted or moved.
- Debug → GUI Appearance → **GUI: panel outlines** is a declarative saved bool,
  `gui_panel_outlines`. Default true preserves other panels' previous appearance. Older configs
  receive the missing field in memory; saved true/false is respected, and loading never writes.
- The global egui window stroke is the derived presentation policy. Windows/popups use it directly;
  custom Debug, planting, backpack, Inspector, FPS/VRAM, Frame Timing and center-card frames use
  `panel_stroke`. No App-only preference copy, per-setting save hook or renderer-side config.
- Disabling outlines makes their color transparent while retaining stroke width, so toggling
  doesn't change frame margins or widget positions. Widget borders, selection indicators, plot
  grids, illustration details, backgrounds and shadows remain intact. The toolbar never gets a border.

## Validation

- `cargo fmt --check`, `cargo check`, `cargo build --release`.
- `cargo test ui_style`: 8 passed, including real egui text/underline rendering, 320/640/1440-wide
  layouts, click routing, disabled input, unchanged selected-label position, and outline on/off/on
  round-trips on planting, backpack and ordinary egui windows without changing layout/controls.
- `cargo test fps_chart`: 11 passed; placement relative to the new toolbar remains valid.
- `cargo test debug_groups`: 8 passed; presentation grouping ownership stays unique.
- `cargo test player_tools`: 19 passed; selection and action behavior are unchanged.
- `cargo test gui_config_loader`: 56 passed, including absent/false/true outline settings and
  save/reload with no writes on load.
- `cargo test every_declared_generic_setting_saves_its_live_value`: passed; new field participates
  in the existing unified live-value saving path.
- Hidden muted Release runs with outlines on and off exited normally, `failures=0`, no
  ERROR/panic/VUID in captured logs. Viewed native captures:
  - `target/ui-text-toolbar-outlines-on.png`
  - `target/ui-text-toolbar-outlines-off.png` (searching the new control)
- Temporary false setting used for the second capture was restored to true. No other saved values
  were changed. Generated GUI bindings were regenerated by cargo, not hand-edited.

These are targeted UI/settings tests and native rendering checks, not full-suite or performance
acceptance. Hover/click checks use real egui input events, not OS mouse automation. No visible game
was launched automatically; final visual preference remains for the user to judge.
