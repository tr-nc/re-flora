# 统一花朵工作台交付

> 此文记录最初仅网页阶段。用户随后批准迁移游戏；当前共用来源、发布协议和验证见
> [游戏统一花型报告](unified-native-flowers.md)。下文“游戏资产未改”等是当时的范围，不是当前状态。

## 范围

在原 `experiments/model-preview/` 后处理 demo 中实现，不新建网页、不改游戏模型资产。用户要求的四瓣／五瓣示例、可调形态、中心形状、贴纸式 palette 着色均可在同一页面调整。入口：`?model=custom-flower`、`four-petal`、`five-star`。

## 建模收敛

`parametric-flower.mjs` 是所有 11 个网页花型的唯一生成器。模型参数包含瓣数、瓣长、瓣宽、圆尖程度、瓣尖缺口、下垂／平展／聚拢、花心半径／高度／平盘圆顶锥顶、大小与仰角。对花瓣中线切向积分后沿两侧展开，瓣尖轮廓与姿态独立；花心和花萼用同一径向表面函数。一次只生成连接点局部的一朵完整花，没有茎或伪动画。

| 预设 | 共用机制的参数表达 |
| --- | --- |
| 野老鹳草、白花老鹳草 | 五片圆宽瓣；同形不同 palette |
| 勿忘草 | 五片短宽瓣、浅眼贴纸；网页不再借波斯菊八瓣缓存模板 |
| 滨菊 | 16 片窄瓣、平黄色花盘 |
| 波斯菊 | 8 片宽瓣、缺口、深浅 palette 过渡 |
| 松果菊 | 12 片下垂瓣、较高锥心 |
| 郁金香 | 6 片聚拢瓣，杯形近似 |
| 星草梅 | 5 片细长尖瓣、极小花心；删除独立 `gillenia-geometry.mjs` |
| 四瓣蓝白 | 4 片宽瓣、平心、瓣中→白缘权重图 |
| 五瓣尖星 | 5 片尖瓣、轻微下垂、脉纹权重图 |
| 自定义花 | 同一个生成器与所有控件，无第二套专用实现 |

预设只是参数、palette 和贴纸模板，没有按物种分支。颜色数据不进入几何 key；改 palette 或贴纸复用几何 UUID 与同一纹理对象。纯几何函数可直接接入未来“种子→参数”或同品种颜色变异，不依赖浏览器随机状态。本轮没有擅自加入随机育种／游戏逻辑。

### 不硬塞的情况

- 原游戏六种花的发布 bank 保持字节一致。新网页花型是迁移候选而非旧顶点复刻；游戏当前四材质角色的 cache 不能直接消费 RGB 权重图，需以后独立批准、扩展发布协议后再同步。
- 郁金香目前是单轮花瓣聚拢成的杯，不是双轮交错且有厚度的真实花被。要做紧闭花苞、重瓣玫瑰、连成钟状的花冠或兰科非径向唇瓣，应增加明确的拓扑族；强行增大宽度会产生穿插，而不是正确拓扑。
- 极大瓣宽配合高瓣数／强聚拢会重叠。这是编辑器允许的形态域，不代表每种参数组合都符合植物学；不隐藏调参端点。
- 32px 保守覆盖会并拢小瓣间缝，细脉可能仅剩几个像素；没有为新花修改成熟后处理来掩盖这些取舍。

## Palette 贴纸

采用四槽非负权重而非连续数字索引；[调研与来源](../research/palette-weight-flower-textures.md) 已保存。

- RGB = A/B/C，D = 剩余量，四者归一化。颜色先转 Linear-sRGB 求权重和，再生成标记为 sRGB 的标准材质颜色纹理。
- 所有瓣共享一块贴纸 UV；另有花心／花萼两个图集岛和边界留白。只有 A/B/C/D 四个颜色选择器，没有按瓣根／中段／瓣缘继续细分颜色 API。
- 模板、软画笔、12 步撤销、原始权重／最终色预览、PNG 导入／导出。导入前检查 PNG 头尺寸与 4 MiB 文件上限，要求 32–512px 且不透明；拒绝后保留原图。异步导入随模型断开或新编辑失效，解码 bitmap 关闭，下载 URL 回收。
- 同一 blue-white 贴纸可换蓝白、莓粉、暮紫 palette；花瓣中心蓝→白缘可见。四槽只覆盖四色的凸组合，不冒充任意色彩绘画。
- 参数仍遵循原 demo 的会话内设置规则；权重 PNG 可保存，不自动写入游戏或上传网络，也未声称已实现完整工程文件保存。

## 验证

- `node --test experiments/model-preview/tests/*.test.mjs`：32 passed。涵盖 11 个统一预设、参数端点／组合、非退化三角形／UV 岛、正负姿态、palette 数学、软画笔、导入约束，以及已发布花／叶／苹果的原有再生成一致性。
- `tests/head-platform-browser.cjs`：11 头模型，控件、前后侧／透视正交、重置、资源计数、贴纸绘制／撤销、PNG 往返、透明图拒绝、palette/贴纸更新不重建几何通过。
- `tests/flowers-browser.cjs`：242 个姿态，8/32/64/128px，原 RGBA 保留，GPU 深度最大差 `0.00002488470022710132`（既有 `0.0001` 上限未改），8 个遮挡夹具，导出透明 512² PNG，重复切换与移动视口通过。
- 用隔离的 agent-browser 会话实际打开工作台、检查控件与截图；已检查 11 花型总览。无新外部网络资源。
- 发现并修复自定义元素误用 HTMLElement 的 `slot` 属性导致构造失败，以及异步文件事件 retarget 后访问 `event.target` 的问题；加入实际 shadow 控件构造和 PNG 往返测试锁定。
- 起始 Node 套件已有一项旧 `8` 物种计数失败（当前原生只有 6 种）；新测试改为验证实际目录和统一生成器，并保留原生发布一致性。一次并发浏览器验证末尾出现 leaf.glb 请求失败，保留错误检查并补充错误文本；完整串行重跑通过，没有放宽断言。
