Why it matters

这轮重构带来了什么？

收益重点不是“文件变得更多或更少”，而是系统行为由明确 owner 负责，并且失败、重试、发布和销毁能够被验证。

01

改动更局部

水、树木、地形连通、DDGI、空间音频等行为由各自深模块封装。新增模式时改 owner 本身，不再跨 App、测试场景和 GPU 提交点同步修改。

02

错误状态更难产生

线性 capability、typed publication、generation identity 和不可伪造 completion 把“顺序正确”从注释提升为结构约束，减少陈旧帧与错误资源配对。

03

失败可以精确恢复

连通性、环境阶段、快照读取和 GPU publication 保留失败请求的精确身份；失败时不提交半成品，下一帧重试原工作而不是近似重建。

04

实时音频更可预测

渲染量子集中拥有混音，声学 publication 使用排序索引与 merge join，PCM 只保留一份 Arc 所有权，完整 Voice 销毁移出实时线程。剩余锁与回收复杂度正在关闭。

05

GPU 生命周期更清晰

DDGI volume、descriptor、frame view 与 builder residency 具有明确身份和发布次序；extent-dependent pipeline 与资源晋升不再依赖分散的隐式约定。

06

验收更接近生产

证据来自真实 runtime completion、当前进程日志、Shader 反射与 release 隐藏运行。源码形状检查只负责精确结构合约，不冒充 Rust/GPU 行为证明。
