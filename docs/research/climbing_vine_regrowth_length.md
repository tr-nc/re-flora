# 藤蔓截断后的再生与长度上限：资料和现状

日期：2026-09-25。仅调研，未改生长逻辑。植物原型按墙面附着的幼态常春藤（*Hedera helix*）理解；不是所有攀援植物通用模型。

## 资料支持的结论

- 常春藤幼态茎用茎生根攀援，成熟阶段可转为不开攀的灌木状生长。RHS 指出修剪可使其维持攀援的幼态，而过度生长的常春藤重剪后能从旧木再生。**失去一段茎并不自然意味着整株永远停长**；但新梢从保留组织再生，不是失去的附着器官凭空恢复。[RHS 常春藤栽培指南](https://www.rhs.org.uk/plants/ivy/growing-guide)，[NC State Extension 物种说明](https://plants.ces.ncsu.edu/plants/hedera-helix/common-name/english-ivy/)
- NC State Extension 将常春藤景观中的攀高范围列为 **20–80 英尺（约 6–24 米）**，并明确 80 英尺是景观植株的潜力；这不是单根茎的精确弧长，也不是所有常春藤在达到某一高度时突然停止的阈值。[NC State Extension](https://plants.ces.ncsu.edu/plants/hedera-helix/common-name/english-ivy/)
- 对 29 种攀援植物的原始研究测得**无支撑搜索梢的最大伸及距离**因物种而异，约 **0.1–2.5 米**；弯曲刚度、茎结构和攀援方式相关。它是从支撑点向外寻找支撑时的力学尺度，**不能**当作已经附着的整株生命周期长度。[Hattermann et al., 2022, *Frontiers in Forests and Global Change*, 摘要与结果](https://doi.org/10.3389/ffgc.2022.836247)
- 因此没有可靠的单一“藤蔓最长 X 米”的生物常数可直接套给当前虚构植株。建议分别定义可达搜索长度、被支撑的存活主茎长度和计算容量；具体游戏单位需要先定义物理尺度，不能把米直接换成体素。以上分层是**游戏设计推论**，非文献给定的数值配方。

## 当前代码为什么剪后不再长

- `src/climbing_plants.rs::revalidate` 会从失去支持的节点向下游标记并裁剪；`prune_marked` 保留上游，创建接在幸存父节点上的芽，但这个芽的 `restart` 保存**被切掉的第一个节点的原位置、接触、背衬和旧附着脚印**。实际是剪到第一个失效节点之前的幸存点，不保证它是几何距离最近的可用附着点。
- `src/climbing_plants/growth.rs::advance` 遇到 `restart` 优先调用 `restart_valid`，只有**原来的那一步**及其旧附着/接触条件全部重新有效，才伸出新节点；否则每次返回“本次不延伸”，不尝试绕过缺口。`rod::step` 在 `restart.is_some()` 时也不会让芽进行正常的探寻运动。这就是**墙未修好时永久等待**的直接原因，不是长到生物极限。现有 `removed_wall_prunes_upper_attached_stem_and_regrows_from_cut` 测试明确要求原墙未修复时不长、修复后才长。
- `growth.rs` 的 `AIR_BUDGET = 64` 是**最近附着点以外的自由搜索弧长**，建立新附着后会重置；不是整株最大长度。`Plant::grow` 另有 `MAX_NODES`（512）存活节点容量；裁剪释放节点位置，但它也不是生物长度上限。剪后 `bud.arc = 0`，所以眼前的永久停长**不是**空气预算耗尽。

## 建议的后续行为（尚未实现）

1. 保留现有事务式支撑验证及下游裁剪；删掉的茎不得悬空或穿过缺口。旧断面可短暂停留，但不能把“恢复原位”作为唯一的再生路径。
2. 从最近的**存活且与根连通**的断面生成新的探索梢；它使用新的局部方向、现有连续弯曲/碰撞/附着判定寻找旁路，同时保留旧墙恢复时可接续的选择。不能沿被删路径穿过失去支撑的墙。
3. 自由搜索预算与整株生长上限分开：前者在新附着后重置；后者若要实现，建议基于**当前根连通的存活主茎 rest-length 之和**（剪掉后回收额度），而不是历史累计出生长度，否则几次裁剪仍会永久耗尽预算。节点容量仍独立作为技术保护。若设计想表达生理年龄/永久衰老，那是另一条明确的规则，而非上述资料直接给出的阈值。
4. 数值未定：当前 64 体素和 512 节点不等于上述米数。需先确认玩法是希望“只要有支撑可继续长，直到场景/资源边界”，还是一个可见的藤蔓最大存活弧长；后一种还需明确世界单位比例、枝条是否计入（目前单主茎）、到达限制后剪短是否重获生长额度。

实现时应用测试覆盖：旧墙一直缺失但邻近有可达支撑时再生；缺口无可达支撑时不穿透且可等待；剪短后从幸存节点再生并回收总长度额度；真正达到所选总长度时才停止，接触/根丧失和未知地形仍事务性安全。
