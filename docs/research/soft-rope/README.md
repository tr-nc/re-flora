# 柔软之物 / Soft Rope Lab

直接用浏览器打开 [index.html](index.html)。保持本文件夹中的 JS 相对路径不变即可离线运行；无需服务、安装依赖或联网。此原型不是游戏截图，也不接入游戏配置、存档或物理世界。

研究证据和候选设计在 [../soft-rope.md](../soft-rope.md)。实现行为以 `simulation.js`、`lab.js` 和可执行测试为准；页面列出的三维、流体与生产碰撞边界不是已实现能力。

## 使用

- 切换麻绳 / 软水管 / 风筝线；拖拽线段附近或端点，松手释放。
- 画布获得焦点后，方向键牵动中点，Escape 松开；也可用 Tab 操作其余表单控件。
- 系统开启“减少动态效果”时默认暂停；“继续”或“吹一阵风”可显式开始。
- 暂停时参数可修改，模拟在继续后应用；重置恢复当前预设，不改变暂停状态或骨架显示选项。
- 长度使用未标定的场景单位，平滑修改静止段长。固定两端间距过大时会约束最短可达长度，因此目标值与当前静止长度可能不同。这不是卷轴放线。
- 离散碰撞不保证高速/已穿透状态恢复；尤其不要把“关闭碰撞后穿过地面，再打开”当作有效碰撞验收。遇到这种情况请重置。

## 验证

从仓库根目录运行：

```sh
node --check docs/research/soft-rope/simulation.js
node --check docs/research/soft-rope/lab.js
node --test docs/research/soft-rope/simulation.test.cjs
```

本轮 12 项测试通过，覆盖固定挂点、默认场景段长误差/整段接触、30/60/144 Hz 分组一致性、风筝无风回落、抗弯差异、拖拽释放、解绑/重绑、渐进长度控制和后台累计步长上限。不是完整数值收敛或性能证明。

已在 Chrome 实际打开离线 HTML，检查 1440×1080 与 390×844 布局及全页内容；验证三预设、暂停/继续、阵风、末端固定、骨架、重置、键盘抓取/松开和真实鼠标拖拽。页面没有 JS 错误，390px 页面无横向溢出。axe 检查没有自动确认的违规；Canvas 覆盖区域的对比度仍属人工检查，不能据此宣称完整无障碍合规。触屏使用 Pointer Events 实现，但未用物理触屏设备验证。

`cargo build --release` 成功；本轮没有 Rust、shader、生成文件或游戏配置变更，因此未重跑原生窗口/GPU 测试。浏览器结果不替代将来的游戏 Release 性能与三维碰撞验证。
