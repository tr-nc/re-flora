# recording.mp4 无缝循环调研

## 范围与观察

目标文件：用户 Downloads 中的 `recording.mp4`。本次仅调研，未修改视频。ffprobe 确认时长 505 秒、1280×720、30 fps，包含 44.1 kHz 音轨。

抽查 0、2、5、250、499、502、504 秒静帧；不是完整观看，也没有听审音轨。画面为固定机位室内人物录像，首帧人物靠近镜头、手托脸；504 秒人物坐得更远、手不托脸。脸部位置、大小、姿势及亮度存在差异，因此直接首尾硬切预计明显。这是基于抽样的判断，尚未搜索最佳接点或实际验证循环观感。

## 常见方法与适用性

1. **匹配动作剪辑 / 搜索相似首尾片段**：优先选择构图、姿态、光照接近且运动方向一致的位置。不能只比较单帧：Video Textures 的钟摆示例表明，外观相似但运动方向相反会产生不自然跳变，需考虑时间邻域。[1] 本片建议先搜索开头和结尾各 30–60 秒，在允许小幅裁剪的情况下找到较好的接点；这个搜索范围是工程建议，不是已经测得的结果。
2. **首尾重叠交叉溶解**：将片尾过渡到片头，背景稳定时成本低，但人物错位会出现双脸、双手。论文示例明确展示 crossfade 的模糊代价，不是“加长溶解就一定无缝”。[1] FFmpeg 的 `xfade` 提供 transition、duration、offset；本机帮助已核对。[3] 对本片建议在匹配接点后比较 0.2、0.5、1 秒过渡，而不是直接长溶解；这些是试验参数，未验证。
3. **正放 + 倒放（ping-pong / bounce）**：Adobe 推荐用于细微、可逆的运动，同时提醒有方向意义的动作会显得不自然。[2] 本片的手、头发、眨眼和可能的说话动作不适合整段倒放；接点相同也不保证速度连续，可能有突然折返。
4. **静态底图 + 局部运动蒙版（cinemagraph）**：Adobe 描述了静帧图层、蒙版和底层运动视频的做法。[2] 适合仅保留窗帘、发丝等局部运动，不适合保留本片全部人物活动；结果属于新的视觉表现，而非忠实保留原录像。
5. **形变 / 光流辅助过渡**：Video Textures 的旗帜案例中，morphing 比单纯 crossfade 更有效地消除了跳变与模糊。[1] 对本片的人脸、手、头发遮挡效果未知，可能产生扭曲，不能将旗帜结果直接外推。应仅在已匹配的短接点上试验。
6. **生成式补过渡**：可作为合成短桥段的探索方向，但本次未验证工具、模型或效果；它会生成原视频不存在的动作，不应承诺人物外观和细节稳定。不是本片的首选方案。

## 正确构造循环

设原片长度 T，重叠长度 d。一种构造为：原片 `[d, T-d)`，接着将 `[T-d, T)` 与 `[0, d)` 交叉溶解。成片长度为 `T-d`，末端再回到原片 d 秒处时保持原来的时间推进。实际实施需按帧边界裁剪，避免重复帧。

这与简单把片尾渐黑、片头渐亮不同；后者会周期性出现黑场。只将两份完整视频接上一次溶解，也不代表输出文件自己的末尾到开头已经处理好。

## 音频与播放器

- 音轨内容尚未听审。有音轨不代表一定有有效声音。
- `acrossfade` 支持重叠、时长和独立淡化曲线。[3] 环境声可试交叉淡化；对白需要避开半句接点，音乐要考虑节拍和乐句。具体接点和曲线需听审，不能仅由视频姿态决定。
- 视频内容连续与播放器无间隙循环是不同问题。MP4 并非对任意播放器都强制无限循环；需要目标播放器启用循环，并在实际环境检查回跳是否有停顿、黑帧和音频空隙。
