# Re: Flora 像素花格美术研究

这是一次**限定在绿色、格子构成、像素植物与离散动效内的视觉研究**。不是新的生产界面，也没有修改游戏。原来的 HTML 实现 demo 已在集成时删除；本目录是用户随后要求的参考板与候选方案。

## 打开

在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/docs/research/splash-art/>。`?variant=A` / `B` / `C` 选择布局；也可直接打开 `index.html`。没有依赖、外部脚本、存储或追踪。参考图已缓存，字体使用仓库现有 Pixelify Sans；只有打开来源链接需要联网。

## 问题与判断

以下是针对当前实现的设计判断，不是引用作品作者的观点：

1. **标题与棋盘没有共同坐标。** 当前标题按视口比例定位，网格独立居中。调整百分比不能保证不同尺寸下都对齐。候选使用固定 10×6 逻辑格，标题严格占整格，进度条也从格线到格线。
2. **白底夺走注意力。** 改成背景系统内部的并格，而非只给白色面板换一个颜色。A 占 4×2 格，B 占 4×1 格，C 占 6×2 格。
3. **重复缺少层次。** 保留规则，但用空格、小叶、两种花型和有限色团调整疏密。花朵由原创的 16×16 局部像素草图生成，未采样参考图片或导入参考素材。
4. **全局同步容易像风车。** 先比较更慢的分组旋转，再与四帧轻摆和少量花心亮点比较。全都离散，不引入连续补间。

**暂推荐 A / 藏绿花圃 + 错拍慢转。** 这是待用户选择的候选，不是已经通过的美术验收。B 和 C 用来判断是否更喜欢细线格或带缝的方片。三套配色均为本页自主选色，非对参考作品的取色或官方调色板。

## 动效与旋转研究

### Sandro Maglione — Pixel art Character Animations guide

<https://www.sandromaglione.com/articles/pixel-art-character-animations-guide>

作者的 idle 示例使用四帧、少量像素位移，以及头发相对身体的一帧延迟。可借鉴的是“少量状态＋局部错拍”的方法，不是把角色动画动作直接移植到花上。页面中的三种花朵动效是自己的设计实验，不能声称来自参考游戏，也不能从静态截图推断其帧时序。

### Aseprite — Rotate

<https://www.aseprite.org/docs/rotate/>

官方介绍选择区域旋转、角度吸附及 Fast Rotation / RotSprite。**旋转后重采样一张新图，与旋转已经像素化的局部方块，不是一回事。** 本项目已选择后者，所以候选固定两张局部像素图，只整体变换；不按每个角度重新栅格化。

### 本页建议参数（不是外部实测事实）

| 方向 | 离散状态 | 时间与分组 | 风险 |
|---|---|---|---|
| 错拍慢转 | 每步 15°，黄白反向 | 每步 1.8 秒、四个相位组 | 依然可能有风车感，需要用户实际观看 |
| 四帧轻摆 | −10° / 0° / 10° / 0° | 每帧 1.2 秒，同样错拍 | 更像风，但不是原先选定的全周旋转 |
| 花心亮点 | 花静止，花心亮／暗 | 仅少量格子参与 | 最安静，但可能不如旋转有生命力 |

## 闭环记录与边界

- 第一版候选的 16px 花瓣过宽、彼此挤在一起，浏览器实图上更像实心星形。第二版拉开花瓣间隙，但白花八瓣太细，显得像雪花。第三版改成更饱满的六瓣白花与五瓣黄花，减少每瓣的明暗碎点，保留局部空间像素化。它们仍是待精修的原创草图。
- 提供旧版示意对照、对齐辅助线、三个布局、三套配色和四种动效（包括静止）；支持暂停和参考图放大。
- 旧版对照是按当前构图规则制作的示意复刻，**不是游戏截图或精确渲染回放**。
- 进度固定 62%，只用于构图比较；不模拟真实加载速度。
- 预览固定为 10×6 逻辑格并整体缩放，不能据此声称已解决游戏所有宽高比和 DPI 下的原生布局。若选中方案，再处理原生全屏边缘的裁切/补格与跨分辨率验证。
- 浏览器验证：1440×1100 与 390×844 下无横向溢出，四张参考图全部加载；A/B/C 切换、旧版对照、对齐线、配色与动效选择、暂停、图片放大及 Escape 关闭均检查通过。标题并格参数全部为整数；旋转在步长之间保持相同角度，在下一步离散变化。浏览器无脚本错误；`node --check study.js`、`git diff --check` 通过。
- 这不是性能测试。未修改 Rust、着色器或个人 GUI 配置；无须为研究页构建游戏。
