# Splash Atelier — 离线美术试验台（Prototype）

这是用于挑选花型／配色的 HTML demo，不是正式游戏 UI。它留在当前实验分支 `spl`，待选定后再把候选移植进游戏。没有网络依赖，没有自动保存，也不会写 `config/gui.toml`。

## 打开

直接用浏览器打开 [`splash-prototype.html`](splash-prototype.html)，或从仓库根目录执行：

```sh
xdg-open docs/research/splash-prototype.html
```

本地字体来自 `assets/font/PixelifySans-VariableFont_wght.ttf`，请保留仓库目录关系。不要只把 HTML 单文件移到其他目录。浏览器不允许读取本地字体时，可用现成的静态文件服务器从仓库根目录提供页面。

## 使用

- **A / B 花型**：先选择黄花或白花槽，再点击花型；马上应用到所有对应格子。可交换两个槽。
- **9 套配色**：原有 forest、moss、pond 原样保留，加上植物标本、暮色薰衣、陶土花园、蓝调时刻、橄榄书页、玫瑰灰。配色切换不覆盖花型。
- **独立颜色**：底色、格线、L 型标记、白花、黄花／进度、花心和标题。可以用颜色选择器或十六进制输入。
- **比例**：网格密度、花朵大小、标题字号、加载进度；默认对应当前原生实现。
- **重播退场**：每次重新抽取种子；格子底色、格线和装饰共同淡出，标题最后消失。时间轴可以暂停在任何时刻。恢复封面保留所选设计。
- **只看画面**：去掉控制面板，按 Esc 返回。画幅支持随窗口、16:9、5:3、竖屏。
- **导出**：JSON 保留所有选择和退场种子；PNG 导出当前画面。刷新会丢失未导出的改动。
- URL 的 `?variant=forest` / `moss` / `pond` / `herbarium` / `lavender` / `clay` / `bluehour` / `olive` / `rose` 可以直接打开配色。底部箭头切换；未聚焦表单时左右方向键也可切换。

## 美术取舍

沿用 [已有研究](splash-art-direction.md) 确定的细线网格与像素植物语言；本轮没有引入或复制新的第三方素材。所有新增花型是自行生成的 16×16 色团，所有新增色板是原创设计候选。

保持构图不变，是为了比较花型和配色，而不是把多个不同布局的差异混在一起。约三分之一的格子仍留给 L 型小标记，作为视觉呼吸；不要让标记比花瓣更亮。两组花最好有轮廓差异，但面积接近。

| 花型 | 轮廓意图 | 建议用途 |
|---|---|---|
| 原版五瓣／六瓣 | 当前游戏基准 | 与新设计比较的参照 |
| 雏菊 | 八条细长瓣、清晰负形 | 与宽圆瓣搭配，不推荐两槽都用细瓣 |
| 波斯菊 | 六片宽瓣、顶端缺口 | 类似纸剪的轻盈、较活泼 |
| 金凤花 | 五片短宽瓣、饱满轮廓 | 温暖苔绿或陶土色板 |
| 紫菀 | 八片杏核尖瓣 | 暮紫、蓝灰，避免碎高光 |
| 梅花 | 五片独立短圆瓣 | 标本纸、玫瑰灰，像小印章 |
| 三叶花 | 三团圆瓣、圆角三角形 | 与六瓣混排，打破重复的放射状 |

优先试这三组：

1. **苔绿 + 金凤花 / 波斯菊**：最接近现有气质，黄色更饱满，白花更松。
2. **蓝调时刻 + 梅花 / 雏菊**：短圆瓣与细长瓣形成有节制的对比。
3. **植物标本 + 三叶花 / 梅花**：浅纸色的平面印花方向；如果白花过轻，应手动增加花瓣与纸色的对比，不把格线整体加深。

## 与游戏的对应关系

布局使用同样的逻辑四格标题、密度 1.6、局部字体 60、16 个错拍相位以及 `−10 / 0 / +10 / 0` 四个轻摆姿势。像素方块在局部空间生成，然后整体旋转，不把每个角度重新栅格化。原版五／六瓣生成参数与 Rust 相同。

退场对应本轮游戏修改：随机延迟 `0～0.65s`、每格淡出 `0.5s`、标题合并格背景最后消失；所有格子在 `1.15s` 前清空，标题与下划线在 `1.15～1.6s` 淡出。HTML 使用同一个 splitmix64 坐标哈希。重绘和窗口缩放保持种子，点击重播才重新抽取。

下层只是原创的简单场景示意，并非游戏截图。浏览器 Canvas 与 egui 的字形度量、透明度混色、边缘抗锯齿不完全相同，不能作为原生渲染或性能验收证据。花型、配色与比例的新增候选只存在于 HTML；游戏本轮仅修改退场。
