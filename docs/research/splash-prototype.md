# Splash Atelier — 离线美术试验台（Prototype）

用于挑选花型／配色的 HTML demo，不是正式游戏 UI。当前迭代**只修改 HTML**：五种花的混排、花色／留空的分层随机、固定进度、标题高度、移除色彩微调，都尚未同步到游戏。没有网络依赖，没有自动保存，不会写 `config/gui.toml`。

## 打开

用浏览器打开 [`splash-prototype.html`](splash-prototype.html)，或从仓库根目录执行：

```sh
xdg-open docs/research/splash-prototype.html
```

字体来自 `assets/font/PixelifySans-VariableFont_wght.ttf`，请保留仓库目录关系。浏览器不允许本地字体时，可以从仓库根目录运行静态文件服务器。

## 使用

- **五种花型**：只保留原版五瓣、原版六瓣、波斯菊、金凤花、梅花。默认全部参与随机混排；点击花型可启用／停用，至少保留一种。每种花都可使用黄、白两色，不再绑定 A／B 槽。
- **重新随机分布**：重新抽取整个构图的种子。配色切换、重绘、轻摆、退场重播不会改变花型和花色的位置；调整画幅、密度或标题位置后，仍按原种子与逻辑格坐标确定内容。
- **9 套配色手札**：原有 forest、moss、pond，加上植物标本、暮色薰衣、陶土花园、蓝调时刻、橄榄书页、玫瑰灰。色彩微调面板已删除；底色、格线和 L 型标记等只使用预设色。
- **比例**：网格密度、花朵大小、标题字号。
- **标题高度**：0～1 的滑杆。0 是最上方完整格子的中心，1 是最下方完整格子的中心，中间按整行切换。标题仍占四格，移动时原位置恢复普通格子；部分裁切的边缘行不作为标题行。
- **加载进度**：滑杆已删除，固定为 **0.69**，包括退场演示期间。
- **退场重播**：只重抽退场顺序；格子底色、格线和装饰共同淡出，标题最后消失。时间轴可停在任意时刻。
- **只看画面**：按 Esc 返回。支持随窗口、16:9、5:3、竖屏画幅。
- **导出**：JSON 保留花型池、所有参数、构图种子和退场种子；PNG 导出当前画面。刷新会丢失未导出的改动。
- `?variant=forest` / `moss` / `pond` / `herbarium` / `lavender` / `clay` / `bluehour` / `olive` / `rose` 可直接打开配色；底部箭头与未聚焦表单时的左右方向键可切换。

## 分布设计

不再使用 `(列 + 行) mod 3` 留空或按奇偶交替花色。

本轮采用 **3×3 分层低差异随机抽样**，不是声称具有蓝噪声频谱的 blue-noise mask：

1. 每个逻辑 3×3 区域独立、随机地排列三格 L 型留空、三格黄花和三格白花。
2. 各区域不复用同一排列，所以不会形成旧版“两个花格、一个空格”的周期斜纹。相邻同色花和相邻留空格均可出现。
3. 局部数量有界，避免纯白噪声产生大片空洞或整片单色。标题覆盖及裁切边缘会让实际可见数量略有差异。
4. 花型使用独立盐值的坐标哈希，从启用的五种轮廓里等概率选择；不强制花型按顺序循环，也不强制每个小区域恰好各一种。
5. 分布在布局构建时计算并缓存；动画帧只绘制。构图种子与退场种子独立。

所有坐标包含负坐标，重绘和调整视口不会重抽同一格的内容。标题移动只是让新的四格区域让位，旧区域恢复该位置原本的内容。

## 美术取舍

沿用 [已有研究](splash-art-direction.md) 的细网格与局部 16×16 像素花语言，没有引入第三方素材。所有新增花型与配色都是原创候选。雏菊、紫菀、三叶花已从 demo 和花型算法中删除。

| 保留花型 | 轮廓意图 |
|---|---|
| 原版五瓣／六瓣 | 当前游戏轮廓基准 |
| 波斯菊 | 六片宽瓣、顶端缺口，类似纸剪的轻盈 |
| 金凤花 | 五片短宽瓣、饱满轮廓，适合温暖苔绿或陶土 |
| 梅花 | 五片独立短圆瓣，像小印章，适合暖纸色与玫瑰灰 |

推荐先看苔绿、陶土花园和蓝调时刻的五花混排。格线与 L 型标记保持低对比，花朵与标题维持阅读层级。

## 与游戏的对应关系

HTML 保留游戏的四格标题、密度 1.6、局部字号 60、16 个轻摆相位以及 `−10 / 0 / +10 / 0` 四姿势。像素方块在局部空间生成后整体旋转，不逐角度重栅格化。原版五／六瓣生成参数与 Rust 相同。

退场仍演示已实现的逐格淡出：随机延迟 `0～0.65s`，每格用 `0.5s` 淡出；标题合并格背景最后消失。所有格子在 `1.15s` 前清空，标题与下划线在 `1.15～1.6s` 淡出。

下层只是原创场景示意，并非游戏截图。Canvas 与 egui 的字体度量、混色、边缘抗锯齿不完全相同，不能作为原生渲染或性能验收证据。游戏代码本轮保持不变。
