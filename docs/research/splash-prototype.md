# Splash Atelier — 离线美术试验台（Prototype）

用于挑选花型／配色的 HTML demo，不是正式游戏 UI。当前迭代**只修改 HTML**：五种花的混排、花色／留空的蓝噪声分布、固定进度、标题高度、字间距、格线粗细和鼠标悬停反馈都尚未同步到游戏。没有网络依赖，没有自动保存，不会写 `config/gui.toml`。

## 打开

用浏览器打开 [`splash-prototype.html`](splash-prototype.html)，或从仓库根目录执行：

```sh
xdg-open docs/research/splash-prototype.html
```

HTML 已内嵌 `assets/font/PixelifySans-VariableFont_wght.ttf` 的原始字节；可以只复制这一份 HTML 到任意目录，离线打开，不再依赖仓库目录关系或外部字体请求。

### 修改与验证

`splash-prototype.html` 是生成文件，不直接编辑。修改 [`splash-prototype.template.html`](splash-prototype.template.html) 后重新生成：

```sh
node scripts/build-splash-prototype.mjs
node scripts/build-splash-prototype.mjs --check
node scripts/validate-splash-prototype-font.mjs
```

最后一条需要 `agent-browser` 及其 Chromium。它会只复制 HTML 到临时目录（不复制任何字体资源），验证内嵌字体与游戏文件逐字节相同，并检查原版标题在不同字间距下确实产生了可见文字像素，同时验证花心覆盖、整花透明度、网格与标题框线粗细，以及悬停偏转和移开恢复。

之前“没有字”的原因已在这个独立打开场景复现：相对字体路径失效，而字体加载保护直接跳过标题绘制。修复是把同一份游戏字体打包入 HTML，不是移除保护后偷偷使用别的字体。

## 使用

- **五种花型**：只保留原版五瓣、原版六瓣、波斯菊、金凤花、梅花。默认全部参与随机混排；点击花型可启用／停用，至少保留一种。每种花都可使用黄、白两色，不再绑定 A／B 槽。
- **重新随机分布**：重新抽取整个构图的种子。配色切换、重绘、轻摆、退场重播不会改变花型和花色的位置；调整画幅、密度或标题位置后，仍按原种子与逻辑格坐标确定内容。
- **8 套配色手札**：原有 forest、moss、pond，加上暮色薰衣、陶土花园、蓝调时刻、橄榄书页、玫瑰灰。偏亮的植物标本已删除。色彩微调面板已删除；底色、格线和 L 型标记等只使用预设色。
- **比例**：网格密度、花朵大小、标题字号。
- **格线粗细**：范围 0～4，默认 1，使用局部 96px 格子的基准单位并随画面缩放。网格线和标题合并格的框线一起调整；0 隐藏这些线，不改变进度下划线或 L 型标记。
- **鼠标悬停**：只在花朵周围的小范围命中，不以整个格子作为热区；留空格和标题不响应。被悬停的一朵向鼠标所在侧偏转到约 ±32°，约一帧内开始反馈，约 150ms 到达明显偏转；移开后平滑恢复原来的 ±10° 离散轻摆。关闭「轻摆」时，悬停仍有效，并恢复冻结姿势。支持纯预览和不同画幅／DPI；触摸操作不触发残留 hover。
- **标题高度**：0～1 的滑杆。0 是最上方完整格子的中心，1 是最下方完整格子的中心，中间按整行切换。标题始终占四格，移动时原位置恢复普通格子；部分裁切的边缘行不作为标题行。
- **字间距**：已删除分字标题 A/B，只保留原版四格合并标题。字间距滑杆范围 −2～12，默认 **7.0**；0 保留原版排字，正值更疏、负值更紧；以局部 96px 格子的基准单位调节，并随画面比例缩放。文字和下划线按同一套可见字形边界居中，下划线保持 69% 进度。
- **标题字体**：内嵌游戏使用的 `assets/font/PixelifySans-VariableFont_wght.ttf` 原始字节，Regular 400。Canvas 等字体加载成功后才画标题，加载失败会提示，不会默默用另一种字体替代。
- **加载进度**：滑杆已删除，固定为 **0.69**，包括退场演示期间。
- **退场重播**：只重抽退场顺序；格子底色、格线和装饰共同淡出，标题最后消失。时间轴可停在任意时刻。
- **只看画面**：按 Esc 返回。支持随窗口、16:9、5:3、竖屏画幅。
- **导出**：JSON 保留花型池、所有参数、构图种子和退场种子；PNG 导出当前画面。刷新会丢失未导出的改动。
- `?variant=forest` / `moss` / `pond` / `lavender` / `clay` / `bluehour` / `olive` / `rose` 可直接打开配色；底部箭头与未聚焦表单时的左右方向键可切换。

## 分布设计

不再使用 `(列 + 行) mod 3` 留空或按奇偶交替花色。

已移除 3×3 分层配额，改为 **多类别蓝噪声邻域优化**：

1. 在 48×48 环绕网格上，把 L 型留空、黄花、白花各随机放入 1/3 的位置。只固定整张图的总数，不固定某行、某列或某个小块的数量。
2. 用各向同性 Gaussian 核（σ=1.5，半径范围 ±5 格）计算同类的邻域聚集能量。进行 40,000 次候选类别交换，降低邻域聚集；加入逐渐降温的退火接受率，避免硬性禁止邻接把格点变成规则棋盘。
3. 同色和留空可以相邻，但大片同类聚集受到抑制。不采用固定的行列交替、局部分块配额，也不要求每格到最近邻的距离完全一致。
4. 48 格环绕边界避免生成区边缘偏差。逻辑坐标查找同一张缓存图，超过 48 格的画幅会出现周期；一般桌面画幅小于一个周期。标题覆盖和视口裁切会改变可见类别数量。
5. 花型仍用独立盐值的坐标哈希，从启用的五种轮廓里随机选择；蓝噪声用于花色与留空，而不是强制五种花型的局部数量。
6. 蓝噪声图仅在构图种子改变时生成，动画帧不重新优化。构图种子与退场种子独立；重绘、配色、字间距、退场和窗口缩放不会重抽类别。

浏览器中用固定种子 1、42、123456 验证：类别总数均为 768 / 768 / 768；低频 Fourier 功率（整数波数半径 1～3，排除 DC）相对相同初始白噪声分别为 0.033、0.042、0.035。说明候选确实抑制了低频聚集，不只是给随机排列换一个名字；这不是完整频谱／各向同性的数学验收，也不是游戏性能证据，最终观感仍以 HTML 视觉比较为准。

所有坐标包含负坐标，重绘和调整视口不会重抽同一格的内容。标题移动只是让新的四格区域让位，旧区域恢复该位置原本的内容。

## 美术取舍

沿用 [已有研究](splash-art-direction.md) 的细网格与局部 16×16 像素花语言，没有引入第三方素材。所有新增花型与配色都是原创候选。雏菊、紫菀、三叶花已从 demo 和花型算法中删除。

| 保留花型 | 轮廓意图 |
|---|---|
| 原版五瓣／六瓣 | 当前游戏轮廓基准 |
| 波斯菊 | 六片宽瓣、顶端缺口，类似纸剪的轻盈 |
| 金凤花 | 五片短宽瓣、饱满轮廓，适合温暖苔绿或陶土 |
| 梅花 | 五片独立短圆瓣，像小印章，适合苔绿与玫瑰灰 |

推荐先看苔绿、陶土花园和蓝调时刻的五花混排。格线与 L 型标记保持低对比，花朵与标题维持阅读层级。

## 与游戏的对应关系

HTML 默认保留游戏的四格合并标题、密度 1.6、局部字号 60、16 个轻摆相位以及 `−10 / 0 / +10 / 0` 四姿势。像素方块在局部空间生成后整体旋转，不逐角度重栅格化。原版五／六瓣生成参数与 Rust 相同。

六瓣花出现额外暗点的绘制问题已复现：源像素轮廓没有内部空洞，但 Canvas 分别抗锯齿绘制花瓣、亮花心、暗花心时，内部颜色交界的覆盖度降到了约 183～187/255，透出深色背景。现在先在局部 128×128 缓存（每个作者像素 8×8）铺完整花瓣底色，再叠花心色，最后整体旋转、等比缩放并一次性应用格子透明度。该绘制修复不改变花型的作者像素，也不删掉原本的花心暗色。回归验证覆盖 −32°/−10°/0°/+10°/+32°、四档缩放和满／半透明共 40 个场景，并验证缓存图与五种花的局部像素数据一致。

随后对三种五瓣花逐一检查，发现真正的两个透明孔来自**梅花**，位于 16×16 作者网格 `(6,6)` 和 `(9,6)`；原版五瓣和金凤花没有内部透明孔。现在用四邻域边界 flood fill 区分外部留白与封闭内部孔，只把封闭孔补成花瓣色。这次仅补上梅花的两个像素，不改变外轮廓、开放花瓣间隙、波斯菊缺口或花心颜色。已加回归检查，确保这两个位置不再透底。

退场仍演示已实现的逐格淡出：随机延迟 `0～0.65s`，每格用 `0.5s` 淡出；标题合并格背景最后消失。所有格子在 `1.15s` 前清空，标题与下划线在 `1.15～1.6s` 淡出。
