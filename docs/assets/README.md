# 仓库资产台账

入口：**[资产包总表](inventory.md)** · **[逐文件 CSV](inventory.csv)**。

这份台账用于逐步核对“目前有什么、游戏是否依赖、是否应该分仓、来源还缺什么”。
它不是一次批量迁移，也不是许可证批准书。未移动素材、未改 Git 历史。

## 怎样看表

- **总表**按资产包/用途分组，适合逐项讨论授权和迁移。
- **CSV**每个文件一行，包含路径、类型、字节数、SHA-256、组 ID、使用状态、分仓建议、来源、缺口、证据路径及是否被当前打包脚本作为散文件复制。可用 Excel/Numbers 筛选。
- **catalog.json**是人工审阅结论的唯一维护入口；CSV 和总表由脚本生成，不直接编辑。
- “未发现游戏引用”只表示在所列审阅基线未找到有效游戏加载/播放路径，**不等于可以自动删除**。文档链接、制作链、历史记录可能仍需要它。
- “预加载”不等于这次游戏实际播放；“编译嵌入”不等于某一帧实际绘制。备用图标可能只在主图标缺失时读取。
- “先核许可”不表示已经确定禁止使用；有购买证明也不代表允许公开原始文件。**私有化不能补救没有商用权的问题。**

## 统计边界

基于 Git 跟踪文件的当前工作树内容，登记：

1. `assets/` 下所有文件，包括模型生成源码、JSON、许可、README 与校验清单。
2. 仓库其他位置的图片、音视频、字体、模型/制作工程、HRTF 数据和 PDF 等已识别媒体扩展名；大小写不敏感。
3. 含媒体 `data:` URI 的 HTML 容器。按 HTML 文件计一个，不展开内嵌媒体数量；JSON 内嵌 atlas 也不拆成虚构的独立文件。

不包括 `target/` 缓存/运行截图、未跟踪文件、外部 URL 的远程资源、Git 历史中已删除的内容。
普通代码、shader、配置、日志和一般文档不作为逐文件资产；`assets/` 外的制作脚本和
provenance/manifest 等说明通过证据链接关联。扩展名集合在 `scripts/asset_inventory.py`，
新格式需要补充。内嵌数据的检测只针对上述 HTML/已登记 JSON，不是对所有源码与归档的递归解包审计。

这比之前仅统计 WAV/PNG 等文件的口径更广：增加了 PDF、视频和内嵌媒体 HTML。
体积是文件字节之和，不是磁盘分配空间或 Git 克隆体积；重复内容仍逐路径计数。

程序生成的树、地形、石材、原生启动屏和树叶声等，不一定有独立素材文件。
例如 `src/stone_models.rs` 生成游戏石材；文档目录的 OBJ 是导出样本，不是游戏读取的模型。
`src/audio/tree_rustle.rs` 合成当前树叶声，旧 WAV 不再被运行时清单加载。

## 分仓优先级

| 优先级 | 涉及资产 | 下一步 |
| --- | --- | --- |
| 明确有公开原件分发限制 | 购买的脚步音效、农具图标、Planets_16x16（含太阳） | 规划私有存放/合法替代；先处理脚步缺失、图标与太阳兜底，再移文件和历史 |
| 已知商用未获许可 | ElevenLabs Free 的喷水器、苹果、微风/强风叶片 | 暂隔离；商用前付费期间重新生成或获得书面许可；付费也不自动解决原件公开分发 |
| 来源/授权需补 | Sound Armoury 两条音效、蝉鸣、9 个工具图标、旧树声/风声参考、宣传图、其它行星包 | 用户逐项提供原始来源、购买/生成信息；不要先假定有权分发 |
| 基础技术数据需核许可 | FAST、STBN、两份 HRTF | 核对应版本的数据许可并补通知；必要时替换为可公开基础数据，不能简单搬走 |
| 有明确公开保留路径 | OFL 字体、项目参数化模型和生成源 | 保留公共基础版，随附许可和制作记录；蝴蝶还应追溯旧参考来源 |
| 非游戏必需但仍有维护价值 | 蝴蝶历史实验、截图、OBJ、PDF、内嵌媒体 HTML | 区分当前制作源与历史输出；可另建研究归档，不必一律私有；论文和旧参考仍核转载权限 |

特别注意：

- `assets/hrtf/` 和 `crates/petalsonic/asset/hrtf/` 各有一份相同数据，必须一起处理。
- `blender-v5/*.blend` 是当前蝴蝶制作源；游戏读取的是 `assets/models/butterfly.glb`。不能把“不是运行输入”理解成“无用”。
- `butterfly-art-workflow.html` 仍内嵌旧参考图。删掉独立 PNG 并不消除所有公开副本。
- 当前 `scripts/package_release.py` 复制整个 `assets/`，另复制 `demo/img/splash.png`。
  因此 CSV 的 `packaged_loose=yes` **不是游戏使用证据**，未接入的 ElevenLabs 文件依然会打包。
  `no` 也不代表成品完全不含该内容，例如 crate HRTF 已编译进二进制。
- 当前 74 条音效已改为显式预加载。完整缺失降级、发行资源筛选、素材分仓和 Git 历史清理都尚未完成。

## 如何维护

```sh
# 新资产先 git add，使它进入跟踪文件范围；不要把私密收据或受限原件加进公开仓库。
# 更新 docs/assets/catalog.json 的来源/缺口/处理建议和证据路径。
python3 scripts/asset_inventory.py
python3 scripts/asset_inventory.py --check
python3 -m unittest discover -s scripts/tests -p 'test_asset_inventory.py'
```

`catalog.json` 的 patterns/exclude 使用大小写敏感的完整仓库相对路径 glob，
`*` 可以跨目录；同一文件匹配多组会报错。新文件无匹配组会列入 `UNREVIEWED`，
脚本返回失败以提示补分类，而不是静默漏掉。优先使用精确文件名和窄目录规则。

**脚本自动维护的是文件、数量、体积、哈希，不是代码依赖和授权结论。**
既有宽规则下的新文件也必须人工检查；尤其新增 WAV 不能仅因同目录而认定会播放。
修改代码加载路径、运行时音效清单、资源用途或打包策略后，需重新审阅分组与证据，
更新 `reviewed_revision` / `reviewed_on` 再生成表格。
`--check` 只验证生成内容一致、匹配无歧义、证据路径存在、无未分类项；
它不自动证明引用仍然有效、所有新格式都已涵盖，或素材已经获授权。

每次补充来源时，也应更新对应资产文件夹内的 provenance/README；台账是索引，
不替代可独立搬运的同目录来源说明。根项目资产许可证不能重新授权第三方内容。
