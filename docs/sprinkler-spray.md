# 单喷口：共享喷流、挡片分流与落地浇水

**Debug → Sprinkler Spray & Motion**。仅保留单口旋转模式；旧 `sprinkler_rotary`
A/B 设置与依赖条件在加载时退休，不写回文件、不覆盖其它保存值。

整机（底座＋转头）烘焙为 **16 个完整姿态**，选最近的喷嘴相对方向。每个姿态拥有相同
中心、半径、采样网格；外部相机方向沿用苹果的全局 `Model direction count`。
不再用转头坐标系单独选视角，也不再对两个部件分别采样。原生路径和缓存过渡也使用同一
完整姿态。连续水源不量化为 16 条射线，喷流保留出生时的方向。

固定机位下的跳格问题在 `51be5b52` 确认：底座与转头实际分属两个缓存与视角框架。
新回归先在旧实现失败（没有 16 个完整姿态），再验证每个姿态包含全部几何、固定底座不变、
只转动喷嘴几何、全部姿态共享包围球。源与 baked sample 的数量随全局方向数增长，不随实例数增长。

## 放置类型：Compact / Tall impact

**Debug → Sprinkler Spray & Motion → Sprinklers: type for new placements** 是持久化选择，
只影响下一次放置。矮款与高款可以共存，删除、渲染发布不改变其它喷头的类型。
旧存档缺项默认 Compact；矮款的原有参数保持不变。Tall 使用带支撑杆的黄铜机头，
喷口额外抬高 22 个模型体素（随硬件尺寸统一缩放），最大水平初速从 0.65 增至
1.05 world units/s，上抛初速从 0.32 增至 0.85，总发射量为矮款 1.8 倍。
仍复用同一条弹道/地形 sweep/接触/光学水滴路径，不增加每个喷头的样本数。
植物不挡水，地形挡水。更长弹道的 sweep 成本并非与矮款相同，尚未做性能验收。

高款与当前矮款外观各保留 16 个完整缓存姿态，因此喷头表面缓存最多为原先两倍；
缓存仍不随喷头实例数增长。外观候选只影响 Compact，不会把已放置的 Tall 改成矮款。

验证：`shader/tests/sprinkler_tall.slang` 直接运行生产弹道，尺寸 0.65 时矮/高峰值
0.0553/0.2852，水平到达距离 0.2756/0.6031。隐藏 Release 的 `rotary-tall` 场景
实测有效水样本 172，其中下降样本 70，峰值 0.2791、距离 0.5798；正常退出。
命令：`RUST_LOG=info RE_FLORA_SPRINKLER_REVIEW=rotary-tall cargo run --release --
--flat-terrain --hidden --mute --auto-exit 12`。这是轨迹/接口验证，不代表植被功能已完成。

## 喷流控制

喷流控制均为声明式、可保存设置，旧配置只补缺项，不覆盖已有值。
下表列出控件**引入时**的默认值；当前已提交的用户设置以 `config/gui.toml` 为准
（30°、5 RPM、5 Hz、30% Duty、mist intensity 6），不会因外观切换而重置：

| 控件 | 范围 | 默认 | 行为 |
| --- | --- | --- | --- |
| Spray angle (degrees) | 10–90° | 40° | 横向全开角；同时改变可见支持和落地分布 |
| Rotation speed (RPM) | 0–60 | 15 | 15 RPM 为四秒一圈；0 停转但可继续喷水；改速不跳转喷头当前朝向 |
| Pulse frequency (Hz) | 0.25–20 | 4 | 每秒开关次数；调频保持阀门当前相位，暂停不积累补喷 |
| Pulse duty (%) | 0–100% | 50% | 每周期打开的比例；默认 4 Hz / 50% 为开 125 ms／关 125 ms；100% 连续；0% 停喷但不停止旋转 |

`Mist & Scattering` 的 **Mist intensity**（原 `sprinkler_mist_density`）为 0–6，引入时默认 **2**，
即原默认光学密度的两倍，不影响浇水。已有自定义值加载时保留，旧控件名称／范围更新。
**Small water droplets** 默认开启，可独立关闭；mist intensity 为零时仍可只看小水滴。
全局 `--no-particles` 只隐藏小水滴，不停止雾与浇水。
方向雾开关仍独立：关闭时显示旧的无方向椭球雾，**它是视觉对照，不是共享喷流的形状预览**。
`Soil Wetting` 的 wetting speed 控制入水量，wet patch scale 控制四级湿度随机量化的空间相关性，
drying speed 控制后续蒸发；它们不为旋转模式定义另一套浇水半径或扇区。

## 小水滴与缓存预算

小水滴是每实例固定 **128** 个出生槽位的解析光学粒子，随世界时间前进，不是每帧
重新随机撒点。其出生位置／速度、喷幅、风、阀门与地形 sweep 复用共享 source/transport；
触地消失，不额外写土壤，不进入 CPU WaterDroplet 灌溉粒子集合。渲染沿用已有雾的深度、
玻璃前界面、光照、tile 和合成路径，使用各自的小型有限支持，不用屏幕噪声伪造颗粒。
缓冲区跟随 acquired frame slot；关闭时清空当前槽，避免切换后读到旧粒子。

整机姿态缓存的样本预算为 `16 × 全局视角数 × N² × 48 bytes`；128 视角、32px 时为
**96 MiB**，由全部喷头共享，不为每个实例复制。新增粒子在最大 256 实例、三帧槽时占
6 MiB。这是稳定态的样本／粒子容量，不含重建时重叠的旧缓存、其它资源，也不是大量喷头性能验收。

本轮控制／粒子验证：1650 app + 4 collider + 1 integration 测试、48 项 Slang 测试，
14 个 Vulkan 同步验证场景、隐藏静音 Release smoke 通过；运行日志见
`target/sprinkler-integrated-review/particles-*`。粒子关闭／全局禁用均读回 0，开启时约
27–28 个存活、墙内约 16 个，无越墙；0.25–20 Hz 阀门积分与 6985 个粒子出生／推进案例通过。
截图在 `target/sprinkler-coupling-review/rotary-contact-particles*.png`。

## 问题记录

### 阶梯坡面形成永久干湿同心环

在 `51be5b52` 的固定速度采样机制上复现，也在加入整机缓存／光学粒子的版本中做了
真实 GPU 对照。八个速度带永远取各自中点，首次接触长期落在少数高度平面；
有限接触支持不能替代对整个速度区间的地形相交积分。转一圈后，未被选中的台阶仍然干燥。
这不是土壤纹理、随机湿度量化或缓存造成的；未对更早版本逐提交回测坡面表现。

- 生产 source/contact 的量化前探针：13 层下降台阶，原采样有 **5 层零入水**。
- 真实场景：14 层、每层高 1 体素、径向宽 6.4 体素，修复前 **5 层零湿体素**；
  修复后 **0 层**。逐层读取的是实际最上层 Dirt 字节，而非推算出的湿圆盘。
- 修复在共享 source 的**积分采样**中：每带内使用 64 个分层位置，按 60 Hz 世界时间
  的 Weyl 序列覆盖；不是固定于渲染帧号，也不锁定喷头转速／阀门周期。暂停保持采样位置。
  每帧仍只有 **8 × 32 = 256** 个雾／接触样本，出水份额相加仍为一。
- 空中体积和真实首次接触从同一采样源生成；不修改土壤纹理、不在接收点撒噪声、
  不增加另一个浇水源。光学小水滴仍按自己的出生槽连续推进，不随积分采样跳位置。

[阶梯回归](../shader/tests/sprinkler_terraces.slang)覆盖平地、1／2 体素台阶、64 个带内位置，
无干环；每次采样核对总出水。30／60／120 Hz 与 0.25／1／4／9／20 Hz 阀门的
累计输入最坏绝对误差为 **0.003716**（不到 0.4 个百分点）。
连续性额外覆盖全部 64 个位置 × 36 组控制组合，保留原固定中点的平均密度守卫；
新位置用两端较低密度识别真正的中间凹谷，避免把弱流顶点附近的陡密度梯度误判为断裂。
原守卫仍为 **0.7692**，全位置凹谷比最低 **0.9571**，均高于 0.6。

证据在 `target/sprinkler-integrated-review/`：`terraces-before.log`、
`terraces-native-{before,after}.{png,json,log}`。相同相机、参数、6 秒时刻的截图对照为
`terraces-comparison.png`（左旧右新，只做相同裁剪、等比缩放和标签）。
这是一个受控坡面的积湿结果，不承诺任意地形的完全均匀或每个像素立即湿透。

### 只浇外环，内部干燥（`51be5b52` 历史修复）

- **影响**：旋转模式在无风平地仍缺少近、中距离入水。扩大横向喷角不能代替射程分布。
  原交替模式与手动 Water 不是本次问题的修复对象。
- **根因**：可见水和土壤虽然已经共享轨迹，但所有水仍有同一组发射速度／仰角，
  只在外侧的一小段射程落地。绕喷头旋转自然累积成空心环；这是发射分布缺失，不是土壤遮挡。
- **时间**：已在上一版 `2b3912a0`（2026-10-20）的生产函数中复现；该版将土壤耦合到
  单一射程的可见喷流。未对更早版本完成独立的引入点回测。
- **修复**：在唯一 source 所有者中加入挡片式速度／仰角分布，让近、中、远水都真正经过
  空中飞行和首次地形接触。不是在地面另画一个湿圆盘，也不额外增加总水量。

修复前的确定性探针显示：距喷头 **0.02、0.05、0.10、0.15** 的圆周平均入水量全部为 **0**，
而 0.28 处为 **4.5943**。基线、诊断与本轮证据保留在 `target/sprinkler-deflector-review/`。
当前回归覆盖 0.012–0.28 的近／中／远距离，以及 0／15／60 RPM × 10／40／90°。
0.012 约为三个地形体素，位于喷口／底座附近；本体占据的中心不等于一块必须浇湿的裸露土壤。

### 前两次修复（历史）

- `d6369a78`：原三臂每口 12 个等间隔年龄样本，XZ 圆形支持忽略旋转造成的年龄间距，
  样本间密度可为零。改为一个真实喷口、48 个二次年龄分区与轨迹定向支持；碰地结束，
  不沿地面滑成烟圈。证据在 `target/sprinkler-shape-review/`。
- `2b3912a0`：此前空中水按历史方向飞行，土壤却用当前方向的独立 60° 扇区。
  平地可见首次接触约 0.7755 秒、距离 0.3062，旧土壤模型在该点的 64 个种子覆盖均为零。
  该版建立共享 source/contact，删除旧旋转扇区及三倍补偿，增加三个保存滑杆。
  证据在 `target/sprinkler-coupling-review/`；其中旧扇区诊断程序仅对应历史 API。

## 共享模型与所有权

1. [sprinkler_spray.slang](../shader/slang/sprinkler_spray.slang)拥有年龄分区、阀门积分、
   出生角、出口／发射速度、拖曳／下落、喷幅、有限支持和散射权重。
   - 一个物理喷口，八个代表性的速度／仰角带；弱、陡的水落近处，强水到远处。
     带内积分位置随世界时间分层覆盖；速度区间本身也随飞行展开，不能只画八条分离的中心线。
   - 以同一发射／阻力模型、喷口高度下的平地环带面积分配出水份额，所有份额相加为一。
     这是挡片的**源流量标定**，不是另一套土壤落点模型；实际地形接触仍单独追踪。
   - 速度区间支持按均匀区间方差 `span²/12` 与有限核方差 `radius²/9` 配准。
     陡近流的定向框架随喷头转动，不在接近竖直时切换成任意世界轴。
   喷头网格和水源仍使用 [sprinkler_animation.slang](../shader/slang/sprinkler_animation.slang)
   的同一个出口与朝向。[SprayClock](../src/sprinkler.rs)积分世界时钟增量，维护有界旋转／
   脉冲相位、粒子时间与带内积分时钟；暂停不补转，tick 回绕不跳变，改 RPM 不重算整段运行时长。
2. [prepare](../shader/slang/sprinkler_mist_prepare.comp.slang)的旋转模式使用 **8 × 32 = 256**
   个速度／年龄区间。一组 64 个线程分段处理全部样本，合并所有区间的可见／接触边界。
   玩家喷头不再进入原交替模式；旧扇区刷仅留在显式土壤噪声诊断中。
   每条轨迹与真实体素地形求首次相交；接触区间同时发布其空中部分和 `SprinklerWaterContact`。
   光学与土壤消费者读同一份结果；没有第二个 emitter registry。
   prepare 在地形绘制前运行，density 为零或选择旧雾外观也不能关闭浇水。
3. [contact](../shader/slang/sprinkler_spray_contact.slang)将**同一有限体积沿实际入射方向**
   投影到接触面，而不是沿地面法线压扁。否则仰角／速度差带来的飞行时间与射程展开会丢失。
   核线积分乘表面余弦，保持每个流量份额的面积积分；扩大喷幅不会创造额外水量。
   投影边界使用同一变换；土壤体素代表其表面面片，不能再向地下偏移半个体素改变足迹。
   age-bin 条件只选择到达边界，不把整条空中喷流立即投影为湿区。
4. [wetting](../shader/slang/sprinkler_wetting.comp.slang)从接触数据计算土壤入水密度，
   检查真实地形遮挡，仅写首次接触表层；后续深入土壤仍由原垂直迁移负责。
   近水可以落在墙前，远水必须被墙挡住，不能要求有墙时连墙内近水也消失。
   固定 `INPUT_AREA` 只校准总入水量，不限定空间范围。
5. 保留四级湿度、相关 Poisson 量化、湿斑尺度、材质与状态位。一个体素只有一个 invocation，
   实例间依次 dispatch；不用对 R8 atlas 做不支持的原子操作，也不让重叠喷头并发丢失更新。
   缓冲区归 acquired frame slot 所有；模式切换时，生产与读回使用相同的实际样本数。

近水与远水有不同飞行时间、不同出生方向滞后。**空中喷流的整个投影不会立即湿透**，
只有接触土壤的部分加水。平地连续转多圈后会累积成覆盖内部的湿区，而不是固定外环。
低占空比确实减少入水，低湿润速度／较强蒸发也会影响积湿速度。

## 近似边界与成本

这是有界解析密度场：用挡片分流作为发射模型，不模拟水撞击实体挡片的流体过程。
用有限条代表性轨迹、短段 sweep 与有限支持重建连续水流，不是逐滴粒子／流体模拟，
也不承诺每个微小水滴都有独立碰撞历史。几乎相切、入射方向无法数值分辨的接触采用
有限法线投影，避免无限投影范围。风、坡面、障碍和边缘会破坏平地上的理想均匀性。

192 样本候选在最窄喷幅出现 **0.5649** 的可见年龄间密度谷值，低于 0.6 守卫；
因此采用 256 样本，而不是放大所有雾团掩盖断裂。当前完整控制矩阵谷值为 **0.7692**。
接触结构增加入射方向后为 **80 bytes**；实例仍为 16 bytes、雾 lobe 仍为 64 bytes。
反射生成由 `cargo check` 完成，不手改生成结构。额外速度带提高了计算和缓冲区成本；
需要用 Release 实测，而非 debug 测试推断大量喷头的性能。

**运行时改喷幅、RPM、频率或占空比会重新求当前场，包括已在空中的部分**，而非逐滴保留旧参数。
例如占空比设为零会立即清掉当前水场。喷头当前角度仍连续，两个消费者仍使用同一新场。
基座目前静态放置；搬运中的源位置历史、极低帧率整帧空间积分、更精细碰撞与跨调参历史
尚未实现。后续应在共享 source/contact 边界改进，不能另拟合土壤扇区。

## 验证与复现

```sh
cargo fmt --check
cargo check
cargo test
python3 scripts/run_slang_tests.py
cargo test sprinkler_shader_pose_matches_water_outlets -- --ignored --nocapture
cargo build --release
node scripts/validate-sprinkler-model.mjs --spray --seconds 8
node scripts/validate-sprinkler-model.mjs --designs --seconds 15
RUST_LOG=info cargo run --release -- --hidden --mute --auto-exit 0.5
cargo run --release -- --tail-latest-log 180
```

- `--designs`：四种造型与七次实时 A/B／候选／cache-native 切换，检查当前选中缓存、
  实际 draw、其它模型 cache key 不变、Vulkan 同步和正常退出。
  输出在 `target/sprinkler-design-review/`。几何测试覆盖四种外观的 16 姿态、喷口、
  固定底座、绕序／法线、8/16/32 采样与仅当前家族占用样本；GUI 测试覆盖补缺、保存、
  关闭后记忆选择及所有非外观帧输入保持不变。这些都不是美术认可或大量实例性能验收。
- [径向覆盖](../shader/tests/sprinkler_radial_coverage.slang)：生产预算下，近／中／远均有入水；
  默认喷幅不靠过量浇中心填洞；旋转后密度场保持协变。包含最窄、最宽、停止和高速旋转。
- [接触契约](../shader/tests/sprinkler_contact_contracts.slang)：每个速度带的可见落点都有水；
  空气／深层／远离支持处无水；平地、墙面、顶面和数值相切情况下保持面积积分与正确边界。
  当前最坏面积积分误差 **0.000125**。0／10／50／90／100% 阀门在 30／60／120 Hz 下
  验证实际到达区间的总输入，0%／100% 保持精确端点；风使用同一传输方程。
- [连续性](../shader/tests/sprinkler_spray_continuity.slang)：36 组角度、转速、相位和风组合，
  原固定中点及 64 个积分位置共 2340 组；同一喷口、亚体素嘴部支持、有限边界和归一化光学量。
- `--spray` **15** 个隐藏静音 Release 场景：连续／50%／0%、intensity=0、四个实时滑杆、
  四面墙、60 RPM、粒子独立开关／纯粒子／墙阻挡／全局禁用、阶梯坡面、resize、放置／移除。
  直接读取 GPU 接触、粒子和土壤字节，检查近／中／远均湿、关阀无水、墙外不漏，带 Vulkan 同步验证。
  场景输出在 `target/sprinkler-coupling-review/`；当前整合日志为
  `target/sprinkler-integrated-review/final-*`。
- 本轮按请求删除旧外观 A/B、修改雾强度默认值、添加频率与粒子控件；除此之外的 GUI 保存值
  保留。测试运行前后核对 GUI／相机哈希，不自动启动可见游戏。

当前整合结果：**1651 app + 4 collider + 1 integration** Rust 测试、**49** 项 Slang CPU
测试、显式 **660** 个 CPU／Slang 姿态案例、**15** 个 Vulkan 同步场景与隐藏静音
Release smoke 通过；smoke 运行日志在 `final-smoke.log` 给出，`final-smoke-tail.log` 确认
`[SHUTDOWN] phase=complete failures=0`。这些不是大量喷头的性能验收。
