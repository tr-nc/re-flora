# 自适应铺路弯道

背景：[现实铺装、Tiny Glade 与旧限制的调研](research/pavement-curves-and-layout.md)。

## 行为合同

- 鼠标在未铺部分画出的缓弯，应利用现有石板的四边形形变能力；某个偏好的圆角半径排不下，不等于这条路不可铺设。
- 光标确定尾部的位置，不必同时确定一个完整转角的最终切线。刚转弯的短尾部，可以先形成一段未完成的弧，再随输入调整。
- 只有真实发布的地形和出口截面不可变。尚未发布的排，包括已编译排队的排，都可以重新规划。
- 接缝、实际石板尺寸、凸性、完整排、地面支撑、已有铺装保护和连续发布仍是硬约束。失败输入不保存为合法历史，不能在障碍另一侧重启铺设。

## 实现

`src/app/path_band/curve.rs` 拥有曲线规划：

1. 从相邻输入线段估计局部曲率，避免把原本平缓的线突然拧到默认圆角半径。
2. 按相邻线段实际可用长度分配圆角切入量，可以局部缩小半径。移除旧的 98% 占用拒绝和 120°角度拒绝；接近完全反向时仍显式断开。
3. 最后一段不够放下完整圆角时，求一条与入射线相切、准确终止于末端输入点的部分圆弧，不要求尚未画出的出射切线。原有输入简化的一体素误差走廊保留。
4. 局部平滑半径／切入量的上界控制流式规划范围，不是物理最小转弯半径。是否可铺，由最终几何判断。

`src/app/path_band.rs` 拥有截面和排的几何事实：

- `course_fits` 对实际道路条带检查严格凸性，取代冻结出口上的 `pitch / width` 角度上限。
- `replan_unpublished` 从 `CourseContinuity` 的实际发布检查点重新生成候选排；不把最远的排队排当成不可修改历史。
- 下一排继承已经发布的确切出口、编号和距离，预览与写入使用同一份排和石板足印。

`src/app/pavement.rs` 拥有石板排布和接缝：

- 沿真实边缘收缝之后，再检查每块石板的最短边及对边间局部厚度。
- 已有的两体素名义宽度下限，现在也作用于变形后的 XZ 足印；这不是一个新转弯半径比例。数学上仍凸、但只有 0.054 个体素短边的薄片不会被当成可用石板。
- 任一必要石板无法生成，拒绝整排，不能悄悄漏掉内侧石板。

交互层不再通过把短尾部光标投影回直线来补救固定圆角的失败。地面快照、真实 GPU 模型写入、实时 atlas 保护和发布路径保持原有所有权与检查。

## 验证

- 两个新增回归在修复前明确失败：三块宽道路的缓弯，以及尚未容纳完整圆角的短尾部。
- 生产候选交互测试覆盖左右弯、18／45／180 次输入、按实际间隔固定端点与释放残段；并验证先发布直线前缀后继续压缩转弯，旧足印／种子和接续出口不变。
- 保留极端保存尺寸、半砖、S 弯、平地／坡地封闭网格、真实回折、旧路重叠、无支撑地面、采样上限与拒绝后恢复的检查。
- `scripts/validate-pavement.sh` 在平地通过生产候选、支撑、GPU 预检和发布路径，验证半径 0.18 与 0.10、宽度 0.12 的左右弯：每个鼠标目标通过、完整排落地、每块内部 atlas 材料正确、重走 atlas 字节不变、保存重载不变。半径 0.10 时，Slabs 四排共 12 块，Brick 四排共 10 块。
- native pointer／continuity／recovery 脚本验证窗口输入路由、危险转弯红色预览、暂停期间 atlas 不变、直接合法目标恢复、已铺前缀不变、实时 atlas 障碍保护，以及释放／取消的声音所有权。拒绝阶段的固定回折角度保留约 160°；旧 recovery 输入逐步减小角度后现在可以合法铺设，不能继续把它作为“必须一直拒绝”的例子。
- `cargo fmt --check`、`cargo check`、`cargo test`、`cargo build --release` 和隐藏静音 Release 启动，配合逐个检查运行日志。

这建立的是几何及真实地形写入证据，不替代玩家对绘制手感、图案外观的批准，也不是性能验收。

## 当前边界

仍然保持固定横向分块和四边形石板。不支持内侧合块、三角块或通用局部重排；当真实接缝／体素尺寸不足或条带折叠时仍拒绝。未宣称复刻 Tiny Glade 的内部算法。

试玩：`cargo run --release -- --flat-terrain`，按 **V** 在平地拖拽铺路。
