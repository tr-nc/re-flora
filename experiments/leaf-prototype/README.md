## 原型回答的问题

- 32 面模型可以表达尖椭圆轮廓、主脉折起、叶尖卷曲与短叶柄。
- 完整保守覆盖会把合理的对角接触补成粗拐角，用户否定了这个处理规则。
- 后续采用八邻接、几何约束的最少补点实验；斜向接触视为完整连接，只补真正断开的可见片段。
- 用户决定保留一个统一的长期美术预览窗口，而不是为每种模型继续复制 demo。统一工具同时接入蝴蝶动画。

迁移验证中，16 个旧叶片 A 样本与新工具逐字节一致。默认 32 像素 B 仍只补一个像素。新工具的补点颜色改为从连接端点重建，不再为叶片单独维护补点材质 shader；这一差异在新说明和界面上明确标示。
