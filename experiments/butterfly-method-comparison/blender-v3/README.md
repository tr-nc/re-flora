# v3：为 12px 重新设计的候选

本轮是美术候选，不是已经批准替换游戏资产。v1/v2、原手绘和游戏代码均保持原样。

## 改动与判断

- 翼面从平薄片改为微拱曲面（cup），加宽翼根、保留一个前后翼腰部；所有角度使用同一几何，未做面向镜头的形变。
- 去掉完整黑色翼框和低于 1px 的触角，用两块主要翼色和较明显的胸部代替细节。胸部提高以减少被翼面遮住。
- 五个关键翼角为 5° / 32° / 60° / 38° / -18°；收翼不再使用第一轮草稿的 72°极端压扁姿态。
- 整体俯仰由 v2 的 -17°至25°收敛至 -7°至8°，保留小幅升沉和腹段跟随，不宣称小图能读出每段动作。
- 所有方向相机统一提升到 60°，正交尺度统一 3.05；源模型、姿态、相机和色块同时调整，所以不能把最终改善全部归因于某一项。
- 原生渲染 **12px**；保留原生 16px 与 128px 对照，不用下采样伪装原生输出、不做逐帧居中或修像素。

已实际检查完整 contact sheet：相比 v2，最薄的横条姿态减少，展开/收拢的形状更连续。当前仍有局限：斜向收翼容易读成一块亮色，胸腹不是每帧都清楚；无黑翼框的配色在浅底对比度较低。这是需要用户看动态决定的候选，不以面积指标代替美术验收。

## 验证

运行环境：Blender 4.5.13 LTS、系统 Python/Pillow。

```sh
# 初次从配方创建，明确会覆盖本目录源模型：
/usr/bin/python3 experiments/butterfly-method-comparison/blender-v3/run.py --rebuild
# 保留手动编辑，默认只导出现有 .blend：
/usr/bin/python3 experiments/butterfly-method-comparison/blender-v3/run.py
```

`BLENDER=/path/to/blender` 可覆盖自动发现。`--draft` 跳过独立重放，不代表完整验收。导出复用 v2 的纯调色板函数，未修改 v2。

实际完整运行结果：

- 12/16/128px × 五方向 × 六个时刻（含末端）共 **90 帧独立重放一致**。
- 五方向×三种尺寸，**15 组首尾循环端点一致**。
- 75 张正式采样帧外边界全透明；二值 alpha、索引 PNG、PLTE 恰好 5 项检查通过。
- GLB 一个 0–1 秒动画、6 条必需通道；由重开保存工程导出。导出前后 `.blend` 哈希不变。
- 12px 最少 18 个不透明像素、最薄 4px 高；16px 最少 34 个不透明像素、最薄 6px 高。仅为诊断，不代表艺术评分。
- Python 语法检查通过，运行日志未发现 error/traceback/exception/failed。未改 Rust/shader，未运行游戏，也不作性能声明。

源、GLB、图集与脚本哈希和逐格测量见 `validation.json`。`source-manifest.json` 描述配方创建的模型；手动修改 `.blend` 后该配方说明不自动更新。实际导出以保存工程为准。

`raw/`、`replay/`、运行日志与 Blender 自动备份不入库；跟踪源工程、GLB、脚本、最终图集、contact sheet 和验证记录。网页入口为 `../comparison-v3.html`；同步控制、GLB 相位及两种视口检查见 [页面验证](browser-validation.md)。
