# Re:Flora 模型像素化预览台

这是持续维护的美术预览工具，不是一次性原型。目录位于既有 `experiments/` 工作区内，以复用本地资源和启动方式。**唯一的新模型接入点是 `models/index.js`，不要再复制一个 HTML demo。**

## 启动

仓库根目录：

```sh
node scripts/serve-model-preview.mjs
```

打开 <http://127.0.0.1:8765/model-preview/>。

- 落叶：`?model=leaf`
- 蝴蝶：`?model=butterfly`
- 布局：`&variant=compare` / `model` / `pixel`

统一工具不使用界面版本编号，也不保留带编号的旧比较页面。`/leaf-prototype/` 与 `/butterfly-method-comparison/` 这两个不带编号的书签入口仍会跳转到对应模型。旧查看器、历史边框实验和旧验证脚本均从当前树移除；历史源在提交 `86b4b81c`。已批准模型资源的内部路径不改动。参数 JSON 的格式标识用于兼容校验，不是界面版本。

需要支持 WebGL 2 的浏览器及 Node 24；不要使用 `file://`。运行无需 npm 安装或构建步骤。服务只监听本机，既提供预览目录，也提供 `assets/models/` 中的正式游戏资源；不再只服务 `experiments/`。Three.js 0.183.0 与许可证继续使用本地 vendor。

蝴蝶的游戏与网页直接读取同一个 `assets/models/butterfly.glb`，不再保留单独的游戏网格／动画导出。共享接口与跨运行时顶点对照见 [正式模型资源](../../assets/models/README.md)。

## 使用

- 顶部选择模型；两个画布共享相机，均可拖动、滚轮缩放和方向键旋转。支持正交/透视、正背侧视角、原始线框和独立的相机转台。
- 左侧保留模型原始材质；右侧是真正的 8–128 像素边长缓冲，最近邻放大。固定观察范围不随动画姿态重新适配，避免拍翼导致像素尺度变化。
- 动画统一支持片段选择、播放/暂停、相位拖动、前后逐帧、2–60 FPS 姿态采样与播放速度。左右总是同一采样时刻。模型切换、预设导入后默认暂停，方便比较。无动画模型的时间轴禁用、采样时间固定为 0。
- 通用像素处理：A 原始中心采样；B 八邻接最少补点；另有默认关闭的亮度色阶处理。叶片材质自己的受光色阶独立保留，不与通用后处理混为一谈。
- B 不保证每个姿态都变化。状态会分别说明「已补像素」「原本已八邻接连通」「仍分离但无允许路径」或「无可见采样点」，不能把补点数为零一概解释为连接成功。可复现的蝴蝶对照：12 像素 → 正面 → 60 FPS 的第 6 帧（0.100 秒），开启 B 会补 2 个像素；默认观察角度的第 0 帧原本已经连通，因此不应改变。
- 模型专属控制：叶子的宽度、折起、卷曲、颜色、叶脉、透光；蝴蝶的统一翼色及光照/自阴影。颜色选择保留 HSV/HEX 自定义面板。
- PNG 导出保存当前原生 RGBA 像素，不含背景/UI；文件名标记模型、A/B、分辨率和动画采样时刻。
- 参数只在内存中。手动导出/导入版本化 JSON，记录模型、材质参数、处理设置、相机、布局、背景与动画时刻。导入会暂停动画，不会执行脚本、载入任意 URL 或修改游戏配置；无效数据不会覆盖现有模型。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `viewer.js` / HTML / CSS | 唯一的交互、相机控制、播放循环、模型切换、预设和下载入口 |
| `timeline.mjs` | 静态/动态统一时间采样与播放推进 |
| `pipeline.js` | 原始/像素绘制、可见组 ID、统一图像处理与资源释放 |
| `geometry.js` | 读取当前动画姿态，世界变换，齐次裁剪，投影到像素格 |
| `connectivity.mjs` | 几何约束的八邻接连通判定与逐条最短补点路径 |
| `postprocess.mjs` | 分组修复、缺失颜色重建、亮度色阶 |
| `presets.mjs` | 预设版本与字段校验 |
| `models/*.js` | 模型资源、材质、专属参数、动画与默认观察设置 |

### 新模型的接口

在 `models/` 提供一个定义，注册到 `models/index.js`。定义包含：

- `id` / `label`：稳定 ID 与显示名。
- `defaults` / `controls`：专属参数与声明式控件（数值范围/步长、复选框、颜色）。所有控件必须对应默认值和可序列化设置。
- `preview`：默认 `resolution`、`background`。
- `async create()`：返回下面的模型对象。加载失败必须释放自己已建立的资源；切换竞态中的过期加载由 viewer 释放。

模型对象包含：

- `scene`、`meshes`：模型及其光源；meshes 不含辅助线框或背景。
- `view: {span,target,offset,axisDistance?,near?,far?}`：固定观察范围、默认目标与相机偏移。
- `clips: [{name,duration}]`：任意数量动画；静态模型为空数组。
- `apply(settings)`：应用专属设置，不触及相机或渲染循环。
- `sample(time,clipIndex)`：取当前姿态；必须可以直接跳到任意时间，而非仅增量推进。
- `preparePass('source'|'pixel')`：可选材质行为通过这个固定接口实现。两个模型都提供该方法；不需要差异时为空操作。
- `shadows`：是否启用场景阴影。
- `repairGroups: [{id,label,meshes}]`：明确允许修复连接的几何组，ID 为非零 RGB 整数、不能重复。未支持修复的模型可返回空数组。一个 mesh 只能属于一个组；本工具当前的两个模型都满足此约束。
- `description`、`dispose()`：状态说明及完整资源清理。

模型只能提供资源/姿态/材质，不能自己创建 renderer、OrbitControls、requestAnimationFrame 或像素处理分支。需要新后处理时只改共享管线。

### 修复分组与颜色

- 叶片与叶柄是一组；蝴蝶左右翼是两个独立组，不通过全局连通性把两翼强行缝起来。
- 几何支持改为动态多字位集，不再限制 32 个三角形；当前蝴蝶实际为 156 面。每个候选步仍需共同的源三角形支持。
- 使用与 A 相同深度测试的 ID pass 识别可见像素属于哪一组，别组已经占据的像素不可作为桥接路径。补点候选之间若竞争一个空像素，取候选几何的近侧深度。
- 新增像素颜色在桥接端点间以线性光插值重建，复用 A 的实际材质结果；不是为每种材质再实现一套着色器。这是相对于旧叶片原型的明确变化：**旧 A 与已有像素不变，B 的新增像素颜色可能不同。**
- 原来斜向连通的区域完全不改；逐条选补点数最少的桥，最后删除可移除的新增像素。不是多区域连接的全局最优解保证。

## 边界与游戏验收

- 预览台负责单模型造型、材质、动画和像素规则的美术比较；游戏仍负责场景尺度、真实环境光、遮挡融合及实例规模下的 Release 性能验收。
- B 是实验选项，默认关闭。包括同步 GPU 小图回读、可见 ID pass 与 CPU 连接搜索，没有游戏性能承诺；目前不能直接用于大量落叶。
- B 当前支持这里的**不透明几何**。未来透明贴图/alpha discard、GPU 自定义顶点变形需要扩展可见 ID 与几何投影约定，不能假装与现有通用流程自动等价。当前动画为 GLB 节点变换；几何采集使用 `getVertexPosition`，但没有另外验收蒙皮/形变资产。
- 完全没有被 A 采到的叶尖、叶柄末端或整片几何不会凭空恢复。补点没有时间稳定滤波，旋转或动画时仍可能跳像素。亚像素真实缝隙和复杂遮挡也不等同于精确三维拓扑分析。
- 不是建模编辑器、资产管理系统或任意文件上传查看器。新 GLB 通过一个模型定义接入；本阶段只承诺已接入的两个模型。

## 验证

快速确定性检查（Node 24，无依赖）：

```sh
node --test experiments/model-preview/tests/*.test.mjs
```

浏览器检查不进入 Cargo 测试套件。安装/使用已有 Playwright 后运行；脚本自建并关闭本地静态服务，Chrome 始终 headless：

```sh
# 若 Playwright 在其它位置，设置 NODE_PATH 指向该 node_modules。
node experiments/model-preview/tests/browser.cjs
```

支持 `CHROME_EXECUTABLE`、`PREVIEW_ARTIFACT_DIR`。设置 `CHECK_REDIRECTS=1` 一并检查已迁移的旧入口跳转。默认工件在 `target/model-preview-validation/`。

本次验证：

- Node 纯逻辑：对角接触不变、单像素斜线、156 面支持无 ID 回绕、不同组不互相缝合、原像素 RGBA 保持、静态/动态时间和所有 2–60 FPS 采样、预设拒绝坏数据。
- Chrome / SwiftShader：模型切换与异步加载竞态、32/156 面、双向鼠标旋转/缩放、正交/透视、8–128 缓冲、分组补点、共享动画、逐帧、HSV/HEX、无光照精确颜色、自阴影、线框不污染像素图、PNG、JSON 往返像素一致及非法预设拒绝。蝴蝶补点专门包含非零补点案例、原本连通不变案例、无允许路径仍分离案例，不仅检查开关是否可点击。
- 1440×1000、1280×720、390×844 截图与无横向溢出；无页面异常、控制台 error、失败请求或外网资源。已查看两模型与手机截图。
- 迁移前保存的 **16 个叶片 A 样本 + 24 个蝴蝶 A 样本**，与新入口在同一浏览器/软件渲染环境下 PNG 逐字节一致。默认叶片 B 仍只补一个像素。
- 最初预览台迁移未改游戏；后续共享资产接入已改 Rust 资源读取，须同时执行 Cargo 检查、测试和隐藏 Release 验证。网页验证不提供游戏性能结论。
